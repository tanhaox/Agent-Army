## 🔧 技术实现方案

### 1. 坐标系转换（关键）

**问题**：百度使用BD09，天地图使用GCJ02，需要转换

**解决方案**：创建坐标转换工具

```typescript
// src/lib/tianditu/coordinateConverter.ts

/**
 * BD09 (百度) → GCJ02 (天地图/高德/腾讯)
 */
export function bd09ToGcj02(lat: number, lng: number): { lat: number; lng: number } {
  const x_pi = (3.14159265358979324 * 3000.0) / 180.0;
  const x = lng - 0.0065;
  const y = lat - 0.006;
  const z = Math.sqrt(x * x + y * y) - 0.00002 * Math.sin(y * x_pi);
  const theta = Math.atan2(y, x) - 0.000003 * Math.cos(x * x_pi);
  const gcj_lng = z * Math.cos(theta);
  const gcj_lat = z * Math.sin(theta);
  return { lat: gcj_lat, lng: gcj_lng };
}

/**
 * GCJ02 (天地图/高德/腾讯) → BD09 (百度)
 */
export function gcj02ToBd09(lat: number, lng: number): { lat: number; lng: number } {
  const x_pi = (3.14159265358979324 * 3000.0) / 180.0;
  const z = Math.sqrt(lng * lng + lat * lat) + 0.00002 * Math.sin(lat * x_pi);
  const theta = Math.atan2(lat, lng) + 0.000003 * Math.cos(lng * x_pi);
  const bd_lng = z * Math.cos(theta) + 0.0065;
  const bd_lat = z * Math.sin(theta) + 0.006;
  return { lat: bd_lat, lng: bd_lng };
}
```

## ⚠️ 风险评估

### 风险1：坐标转换精度损失

**风险等级**: 🟡 中等

**描述**：BD09 → GCJ02 转换可能有精度损失

**缓解措施**：
- 实施前进行精度测试
- 如果偏差 > 10米，考虑优化转换算法
- 保留百度服务作为备份

### 风险2：天地图API不稳定

**风险等级**: 🟢 低

**描述**：政府平台可能有维护期

**缓解措施**：
- 添加重试机制
- 添加降级方案（返回简化数据）

**缓解措施**：
- 监控每日API用量
