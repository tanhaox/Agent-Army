
- 端口：15432
- 用户：postgres / postgres

## 🎯 项目概览

### 项目简介

**秒应** - 基于 AI 的网约车智能订单管理与推荐系统

### 核心功能

1. **AI 智能识别** - 通过 OCR 识别订单截图（准确率 ≥98.2%）
2. **热力地图** - 百度地图集成，订单点位可视化
3. **智能推荐** - 基于时间、地点、金额的多维度推荐
4. **积分系统** - 完整的积分发放、购买、记录管理
5. **航班预测** - 双机场航班到达预测（PEK/PKX）

### 技术栈

**前端**：Next.js 16 + React 19 + TypeScript 5 + Tailwind CSS 4
**后端**：Next.js API Routes + Drizzle ORM
**数据库**：PostgreSQL 16 + PostGIS（地理空间）
**外部服务**：百度OCR、百度地图API

```bash
# 查看所有数据库
docker exec miaoying-postgres psql -U postgres -c "\l"

docker exec miaoying-postgres psql -U postgres -d beijing_didi -c "\dt"
```

### Q: 修改页面后看不到新功能？

**A**: 清除缓存

```bash
# 1. 停止服务器
Close-Miaoying.bat

# 2. 删除 .next 缓存
rmdir /s /q C:\AI-Agent-Local\miaoying\.next

# 3. 重启服务器
Start-Miaoying-Production.bat
```

### Q: 数据库连接失败？

**A**: 检查Docker容器

```bash
# 检查容器
docker ps | grep miaoying-postgres

# 重启容器
docker-compose restart postgres
```
