## 🐛 Bug修复

### 1. 天地图地理编码响应解析错误 ⭐ 核心修复

**问题描述**:
- 订单创建时，地理编码返回 `undefined, undefined`
- 导致所有订单缺少起点/终点坐标数据
- 最终导致公里数显示为 0

**根本原因**:
- 代码期望天地图API返回格式：`{ result: { location: {...} } }`
- 实际天地图API返回格式：`{ location: {...} }`
- 数据结构不匹配导致解析失败

**修复内容**:
- 修改文件：`src/lib/tianditu/geocode.ts`（第151-170行）
- 修复：将 `data.result.location` 改为 `data.location`
- 修复：将 `data.result.address` 改为 `location.address`
- 添加：使用 `location.keyWord` 作为备用地址字段

**测试验证**:
```bash
# 天地图API测试
curl "http://api.tianditu.gov.cn/geocoder?ds=%7B%22keyWord%22%3A%22北京马家堡丽水园%22%7D&tk=xxx"

# 返回正确数据
{
  "location": {
    "lon": "116.373171",
    "lat": "39.834861"
  }
}
```

## 📝 技术细节

### 修改前后对比

**修改前**:
```typescript
if (!data.result || !data.result.location) {
  return { success: false, error: '无返回结果' };
}
const location = data.result.location;
const address = data.result.address || data.result.formatted_address;
```

**修改后**:
```typescript
if (!data.location) {
  return { success: false, error: '无返回结果' };
}
const location = data.location;
const address = location.address || location.formatted_address || location.keyWord || address;
```
