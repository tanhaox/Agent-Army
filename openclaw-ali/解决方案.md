# 通过 SSH 隧道访问 Control UI

## 🚀 快速解决方案

在你的本地 Windows PowerShell 执行：

```powershell
ssh -L 18789:127.0.0.1:18789 root@112.126.61.223
```

保持这个 SSH 连接打开，然后在浏览器访问：

```
http://localhost:18789/#token=b65090c779a6fb8d11b4f39db2028fb8ec893d5b04f65359
```

这样浏览器认为是 localhost 安全上下文，就不会报错了！
