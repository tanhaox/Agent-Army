## 🚀 安装方式选择

### 方式 A：npm 全局安装（推荐，更简单）

服务器已有Node.js环境，直接npm安装最方便：

```bash
# SSH连接服务器
ssh root@112.126.61.223

# 全局安装 OpenClaw-CN
npm install -g openclaw-cn@latest

# 验证安装
openclaw-cn --version

# 运行配置向导
openclaw-cn onboard
```

### 方式 B：Docker 安装（需要先安装Docker）

如果需要容器化部署，先安装Docker：

```bash
# SSH连接服务器
ssh root@112.126.61.223

# 安装Docker
curl -fsSL https://get.docker.com | sh

# 启动Docker服务
systemctl start docker
systemctl enable docker

# 验证Docker
docker --version

# 使用一键安装脚本
curl -fsSL https://clawd.org.cn/install.sh | bash
```
