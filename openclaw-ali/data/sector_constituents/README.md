# 板块成分股数据 - 使用说明

## 概述

由于东方财富API、AKShare等数据源都被严格限制，我们采用**静态数据+定时更新**的方案来管理A股板块成分股数据。

## 数据特点

- **数据来源**：中证指数公司官网（https://www.csindex.com.cn/）
- **覆盖范围**：20个主要板块，59只成分股
- **数据类型**：行业板块成分股（金融、科技、医药、消费、新能源等）
- **更新频率**：每半年一次（指数成分股调整周期）

## 文件说明

### 数据文件

| 文件 | 说明 |
|------|------|
| `sector_constituents_static_latest.csv` | 最新版（主文件） |
| `sector_constituents_static_YYYYMMDD.csv` | 历史版本（按日期归档） |
| `*_latest.backupYYYYMMDD.csv` | 自动备份文件 |

### 脚本文件

| 脚本 | 说明 |
|------|------|
| `create_static_sectors.py` | 生成静态板块数据 |
| `auto_update_sectors.py` | 自动更新和备份 |
| `install_crontab.py` | 安装定时任务 |

## 使用方法

### 1. 手动更新数据

```bash
cd /root/openclaw-ali/scripts
python3 create_static_sectors.py
```

### 2. 自动更新（推荐）

#### 安装定时任务

```bash
cd /root/openclaw-ali/scripts
python3 install_crontab.py install
```

#### 定时任务配置

- **执行时间**：每月1号、15号 9:00
- **执行内容**：
  1. 备份现有文件（格式：`文件名.csv.backupYYYYMMDD`）
  2. 更新板块数据
  3. 清理180天以上的旧备份

#### 查看定时任务

```bash
crontab -l
```

#### 卸载定时任务

```bash
python3 install_crontab.py uninstall
```

### 3. 测试运行

```bash
python3 auto_update_sectors.py
```

### 4. 查看日志

```bash
tail -f /root/openclaw-ali/scripts/auto_update.log
```

## 手动更新建议

虽然设置了自动更新，但由于成分股变化很慢，建议：

1. **每半年检查一次**（6月、12月）
2. **访问中证指数官网**下载最新数据：
   - 网址：https://www.csindex.com.cn/
   - 路径：数据下载 → 指数成分股
3. **更新脚本中的数据**（`create_static_sectors.py`）

## 常见问题

### Q: 为什么不使用API自动获取？

A: 东方财富API、AKShare都被严格限制，无法稳定连接。静态数据更可靠。

### Q: 板块成分股多久变化一次？

A: 指数成分股通常每半年调整一次（6月、12月）。

### Q: 如何添加更多板块？

A: 编辑 `create_static_sectors.py`，在 `SECTOR_DATA` 列表中添加新的板块和股票。

### Q: 备份文件会占用多少空间？

A: 每个备份文件约4-5KB，保留180天约20个文件，总计约100KB，可以忽略不计。
