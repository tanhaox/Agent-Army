## 📝 常用管理命令

```bash
# SSH 连接服务器
ssh root@112.126.61.223

# 查看 Gateway 状态
openclaw gateway status

# 重启 Gateway
openclaw gateway restart

# 停止 Gateway
openclaw gateway stop

# 启动 Gateway (LAN 模式)
openclaw gateway --bind lan

# 查看日志
tail -f /tmp/openclaw/openclaw-*.log

# 查看配置
openclaw config get

# 运行诊断
openclaw doctor
```

## 🔄 如何重启 Gateway

如果 Gateway 意外停止，执行以下命令：

```bash
# SSH 登录后执行
pkill -f "openclaw.*gateway"
nohup openclaw gateway --bind lan > /tmp/gateway.log 2>&1 &
```

或者使用服务命令：

```bash
openclaw gateway restart
```
