# Evaluation-Driven Development Skill

**版本**: 1.0.0
**状态**: ✅ 生产就绪

---

## 🎯 概述

这是一个 **Claude Skill**，教 Claude 使用 **4 阶段评估驱动开发工作流**，自动实现质量门控和迭代优化。

**核心流程**: Research → Implementation → Review → Evaluation

---

## ✨ 特性

- ✅ **自动质量评估** - 0-10 分量化评分
- ✅ **质量门控** - Excellent/Good/Acceptable/Needs Work
- ✅ **自动迭代** - 未达标自动优化
- ✅ **5 大类代码审查** - 安全、性能、风格、文档、测试
- ✅ **智能模型选择** - 根据任务类型自动选择 Opus/Sonnet/Haiku
- ✅ **实时进度跟踪** - 可视化开发进度

---

## 🚀 快速开始

### 安装

1. 下载此技能文件夹
2. 在 Claude 中打开 **Settings > Capabilities**
3. 在 **Skills** 部分点击 **Upload Skill**
4. 选择此技能文件夹
5. 启用技能

### 使用

**方式 1: 自然语言触发**
```
你: 使用评估驱动开发实现用户认证功能

Claude: [自动执行 4 阶段工作流]
```

**方式 2: 直接描述需求**
```
你: 实现一个高质量的用户认证 API

Claude: [识别需求，自动使用评估驱动开发]
```

## 📊 质量门控标准

| 等级 | 分数 | 含义 | 行动 |
|------|------|------|------|
| **Excellent** | 9.0-10.0 | 优秀 | 可直接部署 |
| **Good** | 7.0-8.9 | 良好 | 小优化即可 |
| **Acceptable** | 5.0-6.9 | 可接受 | 修复重要问题 |
| **Needs Work** | 0.0-4.9 | 不足 | 需重新实现 |

```

└─────────┘    └─────────┘    └─────────┘    └─────────┘
```
