# 安装和测试指南

## 📋 前置要求

- Claude Code 账户（Pro/Team/Enterprise 计划）
- Code execution and file creation 已启用
- AI-Agent-Local 项目已设置

---

## 🚀 安装步骤

### 步骤 1: 准备技能文件夹

确保技能文件夹结构完整：
```
evaluation-driven-development-skill/
├── .claude-skill/
│   └── skill.json
├── SKILL.md
├── README.md
└── examples/
    ├── basic_usage.md
    └── advanced_usage.md
```

### 步骤 2: 上传技能到 Claude

1. 打开 Claude Code
2. 点击 **Settings** (⚙️)
3. 选择 **Capabilities**
4. 找到 **Skills** 部分
5. 点击 **Upload Skill** 或 **添加技能**
6. 选择 `evaluation-driven-development-skill` 文件夹
7. 等待上传完成

### 步骤 3: 启用技能

1. 在 Skills 列表中找到 **Evaluation-Driven Development**
2. 打开开关启用技能
3. 技能现在已就绪！

## 🐛 故障排除

### 问题 1: Skills 部分不可见

**原因**：Code execution 未启用

**解决**：
1. Settings > Capabilities
2. 启用 **Code execution and file creation**
3. 启用 **Skills**

---

### 问题 2: 技能上传失败

**常见原因**：
- 文件夹结构不完整
- skill.json 格式错误
- 缺少 SKILL.md 文件

**解决**：
1. 检查文件夹结构是否完整
2. 验证 skill.json 是否为有效 JSON
3. 确保 SKILL.md 存在

---

### 问题 3: Claude 没有使用技能

**可能原因**：
- 技能未启用
- 触发词不够明确

**解决**：
1. 检查技能开关是否打开
2. 使用明确的触发词：
   - "使用评估驱动开发..."
   - "实现高质量..."
   - "4阶段开发流程..."

---

### 问题 4: 执行失败

**可能原因**：
- 缺少依赖文件
- 路径不正确

**解决**：
1. 确保 `shared/subagents/` 文件存在
2. 检查 Python 环境
3. 查看错误日志

## 💡 使用技巧

### 技巧 1: 明确质量要求

```
✅ 好的用法：
"开发一个支付系统，质量要求 9.0+"

❌ 不好的用法：
"开发一个支付系统"
```

### 技巧 2: 利用自动触发

```
✅ Claude 会自动识别这些关键词：
- "高质量"
- "生产级"
- "质量保证"
- "最佳实践"
```

### 技巧 3: 组合使用

```
可以同时使用多个技能：

并用代码审查技能检查代码"
```
