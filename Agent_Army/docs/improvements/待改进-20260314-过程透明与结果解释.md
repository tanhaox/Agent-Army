**创建日期**: 2026-03-14
**优先级**: 🔴 高
**预计工作量**: 2-3小时
**影响范围**: Web UI, 工作流引擎, Agent

---

## 📋 需求描述

### 用户反馈

> "整个生产过程比较黑箱。我也无法评判好坏。"

### 核心问题

1. **过程不透明**：用户看不到Agent在做什么，不知道使用了什么数据
2. **结果无解释**：用户不知道为什么得出75分，不知道哪些因素影响了结论

### 目标

1. **过程透明**：让用户能审查输入资源（数据源）的质量
2. **结果解释**：让用户能判断输出结论的可信度和调整方向

### 改进1：过程日志系统

**目标**：实时显示每个Agent的执行步骤和数据源

**实现位置**：`src/workflows/investment_analysis_workflow.py`

**新增数据结构**：
```python
@dataclass
class AnalysisStep:
    """分析步骤"""
    agent_name: str
    step_name: str
    status: str  # pending, running, completed, failed
    input_data: Dict[str, Any]  # 输入数据摘要
    output_data: Dict[str, Any]  # 输出数据摘要
    data_quality: str  # high, medium, low
    timestamp: str
    duration: float  # 秒

@dataclass
class AnalysisProcess:
    """完整分析过程"""
    stock_code: str
    steps: List[AnalysisStep]
    total_duration: float
    data_sources: List[str]  # 使用的数据源列表
    quality_warnings: List[str]  # 数据质量警告
```

**工作流改造**：
```python
async def analyze_stock_with_logging(self, stock_code: str) -> Tuple[InvestmentReport, AnalysisProcess]:
```

### 改进2：结果解释引擎

**目标**：解释为什么得出这个评分，哪些因素加分/减分

**新增文件**：`src/explanation/result_explainer.py`

**核心类**：
```python
@dataclass
class ScoreBreakdown:
    """评分分解"""
    dimension: str  # 维度名称
    weight: float  # 权重
    raw_score: float  # 原始评分
    weighted_score: float  # 加权评分
    factors: List[Dict]  # 影响因素列表

    # 因素示例：
    # {
    #     "name": "ROE连续3年>15%",
    #     "impact": "+20分",
    #     "value": "15.2%",
    #     "trend": "稳定上升"
    # }

@dataclass
class Explanation:
    """完整解释"""
    stock_code: str
    overall_score: float
    breakdowns: List[ScoreBreakdown]  # 各维度分解
    decision_points: List[str]  # 关键决策点
    sensitivity: Dict[str, float]  # 敏感性分析
    confidence: float  # 置信度
    warnings: List[str]  # 警告信息

class ResultExplainer:
    """结果解释器"""

    def explain_report(self, report: InvestmentReport) -> Explanation:
        """生成报告解释"""

        breakdowns = []

        # 1. 产业分析分解 (40%)
        industry_breakdown = ScoreBreakdown(
            dimension="产业分析",
            weight=0.4,
            raw_score=report.industry.score,
            weighted_score=report.industry.score * 0.4,
            factors=[
                {
                    "name": "行业周期",
                    "impact": "+15分" if report.industry.industry_cycle == "成长期" else "-10分",
                    "value": report.industry.industry_cycle,
                    "trend": "向上"
                },
                {
                    "name": "市场地位",
                    "impact": f"+{report.industry.industry_rank * 5}分",
                    "value": f"第{report.industry.industry_rank}名",
                    "trend": "稳定"
                },
                {
                    "name": "行业增长",
                    "impact": "+10分" if report.industry.industry_growth > 8 else "-5分",
                    "value": f"{report.industry.industry_growth}%",
                    "trend": "向上"
                }
            ]
        )
        breakdowns.append(industry_breakdown)

        # 2. 基本面分析分解 (60%)
        fundamental_breakdown = ScoreBreakdown(
            dimension="基本面分析",
            weight=0.6,
            raw_score=report.fundamental.score,
            weighted_score=report.fundamental.score * 0.6,
            factors=[
                {
                    "name": "ROE连续3年>15%",
                    "impact": "+20分",
                    "value": f"{report.fundamental.details['financial_data']['roe']}%",
                    "trend": report.fundamental.roe_trend
                },
                {
                    "name": "营收增长",
                    "impact": "+15分" if report.fundamental.revenue_growth > 10 else "-5分",
                    "value": f"{report.fundamental.revenue_growth}%",
                    "trend": "向上"
                },
                {
                    "name": "净利润增长",
                    "impact": "+15分" if report.fundamental.profit_growth > 15 else "-5分",
                    "value": f"{report.fundamental.profit_growth}%",
                    "trend": "向上"
                },
                {
                    "name": "资产负债率",
                    "impact": "-10分" if report.fundamental.details['financial_data']['debt_ratio'] > 50 else "+5分",
                    "value": f"{report.fundamental.details['financial_data']['debt_ratio']}%",
                    "trend": "稳定"
                }
            ]
        )
        breakdowns.append(fundamental_breakdown)

        # 3. 关键决策点
        decision_points = []
        if report.overall_score >= 80:
            decision_points.append("综合评分≥80分 → 强烈推荐买入")
        elif report.overall_score >= 70:
            decision_points.append("70≤综合评分<80 → 建议买入")

        # 4. 敏感性分析（如果某个指标变化，评分会如何变化）
        sensitivity = {
            "ROE下降5%": report.overall_score - 5,
            "营收增长下降10%": report.overall_score - 8,
            "负债率上升10%": report.overall_score - 3,
        }

        # 5. 置信度（基于数据质量）
        confidence = 0.8 if "示例数据" in str(report) else 0.95

        # 6. 警告信息
        warnings = []
        if confidence < 0.9:
            warnings.append("⚠️ 使用示例数据，仅供参考")
        if report.industry.industry_growth < 5:
            warnings.append("⚠️ 行业增长率低于5%，增长乏力")

        return Explanation(
            stock_code=report.stock_code,
            overall_score=report.overall_score,
            breakdowns=breakdowns,
            decision_points=decision_points,
            sensitivity=sensitivity,
            confidence=confidence,
            warnings=warnings
        )
```

```python
# 在分析过程中实时显示日志
st.markdown("### 📊 分析过程")

# 进度容器
process_container = st.container()

with process_container:
    # Step 1: 产业分析
    st.markdown("#### [1/2] 🏗️ 产业分析中...")

    col1, col2 = st.columns([3, 1])
    with col1:
        st.markdown("- 📊 分析行业定位...")
        st.markdown("- 📈 评估产业周期...")
        st.markdown("- 🔍 识别增长驱动因素...")
    with col2:
        st.info("数据源: 示例数据")
        st.warning("⚠️ 质量中等")

    # Step 2: 基本面分析
    st.markdown("#### [2/2] 📊 基本面分析中...")

    col1, col2 = st.columns([3, 1])
    with col1:
        st.markdown("- 💰 财务数据分析")
        st.markdown("  - 营收: 100亿 (+15.5%)")
        st.markdown("  - 净利润: 10亿 (+18.2%)")
        st.markdown("  - ROE: 15% (稳定上升)")
        st.markdown("- 📊 盈利能力评估...")
    with col2:
        st.info("数据源: 示例数据")
        st.success("✅ 数据完整")

# 执行按钮
if st.button("🔍 开始分析", type="primary"):
    # 执行分析并获取过程日志
    report, process = asyncio.run(workflow.analyze_stock_with_logging(stock_code))

    # 显示过程日志
    st.markdown("### 📝 分析过程日志")
    for step in process.steps:
        with st.expander(f"{step.agent_name} - {step.step_name} ({step.duration}秒)"):
            st.markdown(f"**输入数据**: {step.input_data}")
            st.markdown(f"**输出数据**: {step.output_data}")
            st.markdown(f"**数据质量**: {step.data_quality}")

    # 显示结果解释
    explainer = ResultExplainer()
    explanation = explainer.explain_report(report)

    st.markdown("### 📊 结果解释")
    st.markdown(f"**综合评分**: {explanation.overall_score:.1f}/100")
    st.markdown(f"**置信度**: {explanation.confidence * 100:.0f}%")

    # 显示评分分解
    for breakdown in explanation.breakdowns:
        with st.expander(f"{breakdown.dimension} ({breakdown.weight * 100:.0f}%权重)"):
            st.markdown(f"**原始评分**: {breakdown.raw_score:.1f}")
            st.markdown(f"**加权评分**: {breakdown.weighted_score:.1f}")
            st.markdown("**影响因素**:")
            for factor in breakdown.factors:
                st.markdown(f"- {factor['name']}: {factor['impact']} (当前: {factor['value']}, 趋势: {factor['trend']})")

    # 显示敏感性分析
    st.markdown("### 🔄 敏感性分析")
    st.markdown("如果以下指标发生变化，评分将如何变化:")
    for scenario, score in explanation.sensitivity.items():
        st.markdown(f"- {scenario}: {explanation.overall_score:.1f} → {score:.1f}")
```

   - [ ] 能看到每个Agent的执行步骤

2. **结果解释**

   - [ ] 能看到警告信息（风险提示）

3. **用户体验**
   - [ ] 信息层次清晰，不杂乱
   - [ ] 关键信息突出显示
   - [ ] 可以展开查看详细内容
