## 🚀 核心特性

### 1. 页面结构

```
📊 分析报告
├── 顶部操作栏（4列）
│   ├── 股票代码输入
│   ├── 报告类型选择
│   ├── 时间范围选择
│   └── 生成报告按钮
├── 报告概览卡片（4个）
│   ├── 综合评分
│   ├── 技术面
│   ├── 基本面
│   └── 风险评估
├── 详细分析区域（展开式）
│   ├── 6大军团卡片
│   ├── 图表可视化
│   │   ├── 雷达图
│   │   └── 趋势图
│   └── 详细数据表格
└── 导出功能（3个按钮）
    ├── PDF报告
    ├── Excel数据
    └── 分享链接
```

### 2. 军团卡片模式

每个军团卡片使用统一结构：
- 背景色：`rgba(ARMY_*, 0.05)`
- 左边框：`4px solid ARMY_*`
- 圆角：`Radius.LG`
- 内边距：`Spacing.P_MD`
- 阴影：`Shadow.SM`

### 3. 图表配置

**雷达图**:
- 评分范围：0-100
- 6个维度（对应6大军团）
- 半透明填充：`rgba(PRIMARY, 0.2)`

**趋势图**:
- 时间跨度：30天
- Y轴范围：60-90分
- 网格线：`rgba(BORDER, 0.2)`
