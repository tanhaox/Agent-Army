# Agent Army 启动说明

## 🚀 快速启动

### 方式1: 双击启动（推荐）

```bash
双击 start.bat
```

### 方式2: 命令行启动

```bash
cd c:\AI-Agent-Local\Agent_Army
python -m streamlit run web_app.py
```

---

## 📋 启动前检查

### 1. 检查Python
```bash
python --version
# 应显示: Python 3.13.x
```

### 2. 检查Streamlit
```bash
python -m streamlit --version
# 应显示: Streamlit 1.30.x
```

### 3. 检查依赖
```bash
pip install -r requirements.txt
```

### 4. 检查文件
```bash
dir web_app.py
# 应显示文件存在
```

## 🔧 常见问题

### 问题1: "web_app.py not found"

**原因**: 工作目录不正确

**解决**:
```bash
cd c:\AI-Agent-Local\Agent_Army
start.bat
```

### 问题2: "Python not found"

**原因**: Python未安装或未添加到PATH

**解决**:
1. 安装Python 3.8+: https://www.python.org/downloads/
2. 安装时勾选 "Add Python to PATH"

### 问题3: "Streamlit not found"

**原因**: Streamlit未安装

**解决**:
```bash
pip install streamlit
```

### 问题4: 端口8501被占用

**原因**: 之前的进程未正常退出

**解决**:
```bash
# 方法1: start.bat会自动杀掉占用进程
# 方法2: 手动杀进程
netstat -aon | findstr ":8501"
taskkill /F /PID <PID>
```

### 问题5: 中文乱码

**原因**: CMD编码问题

**解决**: 已在新版start.bat中避免中文字符
