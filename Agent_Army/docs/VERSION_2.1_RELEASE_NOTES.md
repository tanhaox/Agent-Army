## 📖 使用指南

### 快速开始

1. **启动应用**:
   ```bash
   start_ps1.bat  # 推荐
   # 或
   start_new_window.bat
   ```

2. **访问页面**:
   - 浏览器打开: `http://localhost:8501`
   - 使用左侧导航栏切换页面

3. **配置API**:
   - 前往"⚙️ 系统配置"
   - 配置Tushare API密钥（必需）
   - 配置OpenAI/Zhipu AI密钥（可选）

4. **创建任务**:
   - 前往"📋 任务管理"
   - 点击"➕ 新建任务"
   - 输入股票代码并执行
