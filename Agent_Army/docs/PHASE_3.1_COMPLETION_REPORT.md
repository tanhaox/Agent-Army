## 🔧 技术实现

### 核心函数

```python
def save_api_key_to_config(api_name: str, api_key: str):
    """保存API密钥到配置文件"""

    # 1. 更新YAML配置
    config[api_name]["api_key"] = f"${{{api_name.upper()}_API_KEY}}"

    # 2. 更新环境变量（当前会话）
    os.environ[f"{api_name.upper()}_API_KEY"] = api_key

    # 3. 保存到.env文件（持久化）
    # 读取.env → 更新密钥 → 写回.env
```

### 配置持久化

**三层保障**:
1. **YAML配置** - 配置模板（${API_KEY}）
2. **环境变量** - 当前会话生效
3. **.env文件** - 重启后依然有效
