## 📝 快速开始

在任何Streamlit页面中使用：

```python
import streamlit as st
from src.core import (
    apply_global_styles,
    toast_success,
    show_skeleton_card,
    show_progress_bar
)

# 1. 应用全局样式
apply_global_styles()

# 2. 使用组件
st.title("我的页面")
show_skeleton_card(3)
show_progress_bar(50, "处理中")
toast_success("操作成功！")
```
