## ❓ 常见问题

### Q1：为什么第一次输入股票名称很慢？

**A**：第一次需要从 AKShare 获取完整股票列表（约5000只），耗时10-15秒。获取后会缓存到本地，后续查询只需0.01秒。

**建议**：启动 Dashboard 前先运行 `init_stock_mapper.bat` 预加载映射。

---

### Q2：缓存多久更新一次？

**A**：默认24小时。可以在 `stock_code_mapper.py` 中修改：

```python
mapper = StockCodeMapper(
    cache_dir="./data",
    cache_expiry_hours=24  # ← 修改这里
)
```

---

### Q3：找不到股票怎么办？

**A**：可能原因：
1. 股票名称输入错误（如包含空格）
2. 股票已退市
3. 新股还未更新到 AKShare

**解决方案**：直接输入6位股票代码

---

### Q4：支持港股吗？

**A**：当前版本仅支持 A股。港股支持计划在未来版本中添加。

## 🛠️ 故障排除

### 问题1：ImportError: No module named 'akshare'

**解决**：
```bash
pip install akshare
```

---

### 问题2：网络超时

**错误信息**：
```
❌ 获取股票映射失败: HTTPSConnectionPool(...): Read timed out
```

**解决**：
1. 检查网络连接
2. 重试初始化脚本
3. 如持续失败，使用 VPN

---

### 问题3：缓存文件损坏

**错误信息**：
```
⚠️ 加载缓存失败: Expecting value: line 1 column 1 (char 0)
```

**解决**：
```bash
# 删除损坏的缓存
del data\stock_code_map.json

# 重新初始化
python scripts\init_stock_mapper.py
```

## 📝 代码示例

### 在代码中使用映射器

```python
from src.utils.stock_code_mapper import (
    get_stock_mapper,
    convert_stock_name_to_code_v2,
    convert_stock_code_to_name
)

# 方式1：使用全局实例
mapper = get_stock_mapper()

# 名称 → 代码
code = mapper.name_to_code_convert("贵州茅台")
print(code)  # 输出: 600519

# 代码 → 名称
name = mapper.code_to_name_convert("600519")
print(name)  # 输出: 贵州茅台

# 方式2：使用便捷函数
code = convert_stock_name_to_code_v2("伊利股份")
print(code)  # 输出: 600887

name = convert_stock_code_to_name("600887")
print(name)  # 输出: 伊利股份
```
