### 方法2: 手动启动

```bash

# 2. 启动服务（使用最终版主程序）
```

```bash

streamlit run web_app_v2_final.py --server.port=8502 --server.address=localhost
```

## ❓ 常见问题

### Q1: 启动失败怎么办？

**A**: 检查Python环境和依赖:
```bash
python --version          # 确认Python 3.8+
pip install streamlit     # 安装Streamlit
pip install plotly pandas pyyaml  # 安装其他依赖
```

### Q2: 端口8501被占用怎么办？

**A**: 使用其他端口:
```bash
streamlit run web_app_v2_final.py --server.port=8502
```

### Q3: 页面显示不正常？

**A**:
1. 清除浏览器缓存
2. 使用无痕模式访问
3. 检查浏览器是否支持WebGL（Plotly图表需要）

### Q4: Agent无法调用？

**A**: Agent调用功能正在开发中（Phase 3），当前仅展示Agent状态。

### Q5: 图表不显示？

**A**:
1. 检查是否安装plotly: `pip install plotly`
2. 检查浏览器控制台是否有错误
3. 尝试刷新页面

### Q6: 如何配置API密钥？

**A**:
1. 点击"⚙️ 系统配置"
2. 选择"🔑 API配置"标签
3. 输入API密钥
4. 点击"保存"
