# Agent Army 8部门制 - Dashboard UI设计

> **版本**: v2.0（精简版）
> **日期**: 2026-03-20
> **架构**: 24个Agent（8部门+总司令+HR）

---

## 一、设计原则

### 1.1 核心设计理念

**模仿edict的三省六部制UI，使用金融术语**

| edict元素 | Agent Army对应 |
|----------|---------------|
| 皇上 | 投资者 |
| 圣旨 | 投资指令 |
| 太子 | 总司令 |
| 中书省 | 研究部 |
| 门下省 | （总司令审核模式） |
| 尚书省 | （总司令派发模式） |
| 六部 | 8个部门 |
| 奏折 | 投资报告 |
| 奏折阁 | 报告库 |
| 旨库 | 金融指挥部 |

### 1.2 UI风格

```
配色方案：
- 主色调：蓝色系（#1E88E5 → #43A047渐变）
- 状态色：🟢 绿色（空闲）、🟡 黄色（忙碌）、🔴 红色（异常）
- 背景：浅灰白（#F5F5F5）
- 卡片：白色（#FFFFFF）+ 阴影

字体：
- 标题：20px Bold
- 正文：14px Regular
- 代码：12px Monospace

间距：
- 卡片间距：16px
- 元素间距：8px
- 页边距：24px
```
