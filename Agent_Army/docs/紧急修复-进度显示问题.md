### 2. 错误处理改进

```python
try:
    # 执行分析...
except Exception as e:
    progress_bar.empty()
    status_text.empty()
    st.error(f"❌ 步骤1失败: {str(e)}")
    st.info("""
    💡 建议检查：
    - 网络连接是否正常
    - API密钥是否配置
    - 查看日志文件: logs/agent_army.log
    """)
```
