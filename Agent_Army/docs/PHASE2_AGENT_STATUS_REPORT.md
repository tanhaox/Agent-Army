## 📊 新增核心功能

### 1. 搜索和筛选 ⭐⭐⭐⭐⭐

```python
# 搜索框
search_query = st.text_input(
    "🔍 搜索Agent",
    placeholder="输入Agent名称、关键词或职责"
)

# 状态筛选
status_filter = st.multiselect(
    "📊 状态筛选",
    ["运行中", "空闲", "异常", "已停止"],
    default=["运行中", "空闲"]
)

# 自动刷新
auto_refresh = st.checkbox("🔄 自动刷新", value=False)
```

**功能**：
- 🔍 支持Agent名称、关键词、职责搜索
- 📊 支持多状态筛选
- 🔄 可选自动刷新（每5秒）

### 2. Agent统计概览 ⭐⭐⭐⭐⭐

```python
# 4个指标卡片

create_metric_card(title="空闲", value="8", icon="💤", color="info")
```

**展示内容**：

- ⚡ 运行中：2（正在执行任务）
- 💤 空闲：8（待命状态）
