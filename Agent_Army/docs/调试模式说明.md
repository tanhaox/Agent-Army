## ❌ **之前方案的问题**

### 问题1：进度条不显示

**原因**：
- Streamlit的`st.progress()`在同步执行时**不会实时更新**
- `asyncio.run()`会**阻塞整个页面**，直到执行完成
- 在阻塞期间，UI无法刷新

**现象**：
```
用户点击"开始分析"
↓
进度条卡在0%不动
↓
等待60秒
↓
突然变成100%（或直接完成）
```

### 问题2：后端日志不显示

**原因**：
- `logger`配置了`enable_console=False`
- 日志只写入文件，不在控制台显示
- 用户需要单独查看`logs/agent-army.log`

**现象**：
```json
// logs/agent-army.log
{"level": "info", "message": "Analysis started", ...}  // ❌ 用户看不到
{"level": "info", "message": "Executing analysis", ...}  // ❌ 用户看不到
```

## ✅ **新调试方案的改进**

### 改进1：UI实时日志

使用`st.code()`显示日志，而不是`st.progress()`

```python
# 创建日志容器
log_area = st.empty()
logs = []

def add_log(message):
    logs.append(f"[{timestamp}] {message}")
    log_area.code("\n".join(logs), language="log")  # ✅ 实时更新
```

**效果**：
```
[11:30:00] ✅ Analysis started
[11:30:00] 📊 Stock code: 601669
[11:30:01] 🔄 Loading IndustryChainAnalyzer...
[11:30:02] ✅ Modules loaded
[11:30:02] 🔄 Configuring analyzer...
[11:30:03] ✅ Analyzer configured
[11:30:03] 🔄 Executing analysis (this may take 30-60 seconds)...
[11:30:45] ✅ Analysis completed in 42.1s
[11:30:45] ✅ Results displayed
```

### 改进2：控制台实时日志

```python
def add_log(message):
    print(log_entry, flush=True)  # ✅ 强制刷新到控制台
```

**效果**：
```bash
# 在CMD窗口中实时看到
[11:30:00] ✅ Analysis started
[11:30:00] 📊 Stock code: 601669
...
```

### 改进3：错误堆栈显示

```python
except Exception as e:
    import traceback
    error_traceback = traceback.format_exc()

    # UI显示
    with st.expander("🔍 View Error Details"):
        st.code(error_traceback, language="python")

    # 控制台显示
    for line in error_traceback.split('\n'):
        add_log(f"  {line}")
```

## 🐛 **调试场景**

### 场景1：卡在某一步

**现象**：
```
[11:30:03] 🔄 Executing analysis (this may take 30-60 seconds)...
[卡住不动]
```

**诊断**：
- 如果卡在这里超过60秒 → `analyzer.analyze()`有问题
- 检查是否有网络超时
- 检查API密钥是否配置

### 场景2：模块加载失败

**现象**：
```
[11:30:01] 🔄 Loading IndustryChainAnalyzer...
❌ ModuleNotFoundError: No module named 'src.agents.business.industry_analyzers'
```

**诊断**：
- 模块路径错误
- 文件不存在
- 依赖未安装

### 场景3：执行失败

**现象**：
```
[11:30:03] 🔄 Executing analysis...
❌ ERROR: Connection timeout
📋 Traceback:
  File "debug_analysis.py", line 85, in <module>
    result_obj = asyncio.run(analyzer.analyze(stock_code))
  ...
```

**诊断**：
- 查看完整堆栈
- 定位具体错误行
- 查看错误原因
