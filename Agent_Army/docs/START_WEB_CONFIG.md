# 🚀 Phase 3.1 Web配置接口 - 启动说明

---

## ✅ 功能已上线

**您现在可以通过Web界面配置API密钥，无需手动编辑任何文件！**

---

## 🎯 快速启动

### 1. 启动Web界面

**方式1：命令行启动**
```bash
cd C:\AI-Agent-Local\Agent_Army
streamlit run web_app.py
```

**方式2：双击启动**
```
双击桌面上的 "Agent Army Web" 图标
```

**方式3：使用启动脚本**
```bash
双击 C:\AI-Agent-Local\Agent_Army\start_web.bat
```

---

### 2. 访问配置界面

```
http://localhost:8501
  ↓
点击左侧 "⚙️ 系统配置"
  ↓
选择 "🔑 API配置管理" 标签
```

---

### 3. 配置API密钥

#### 配置智谱AI（必需）

```
1. 展开 "🤖 智谱AI（主力模型）"
2. 输入API密钥（密码模式）
3. 点击 "🔍 测试连接"（验证密钥）
4. 点击 "💾 保存配置"
5. 完成！✅
```

#### 配置Tushare（必需）

```
1. 展开 "📊 Tushare（财务数据）"
2. 输入API密钥
3. 点击 "🔍 测试连接"
4. 点击 "💾 保存配置"
5. 完成！✅
```

## 📊 功能说明

### Tab 1: 🔑 API配置管理

**支持配置**：
- ✅ 智谱AI - 必需（日常分析、搜索）
- ✅ Tushare - 必需（财务数据、行情）
- ✅ DeepSeek - 可选（基准测试）
- ✅ OpenAI - 可选（关键决策）

**功能**：
- 输入框（密码模式）
- 测试连接（一键验证）
- 保存配置（自动保存）

---

### Tab 2: 📊 数据源管理

**财务数据源**：
- Tushare（优先级1）
- 东方财富（优先级2）
- 同花顺（优先级3）

**新闻数据源**：
- 东方财富（优先级1）
- 新浪财经（优先级2）

**自动切换机制**：
```
优先级1失败 → 自动切换优先级2 → 自动切换优先级3
```

---

### Tab 3: 📋 配置文件

**查看**：
- 配置文件存在状态
- 环境变量设置状态

---

### Tab 4: 🧪 测试工具

**批量测试**：
- 一键测试所有API连接
- 显示工具库状态
- 实时进度显示

## 💡 使用示例

### 场景1：首次配置

```

4. 查看工具库状态
```

## ⚠️ 注意事项

### 安全性

1. **密码模式输入**：密钥不可见
2. **保存到.env文件**：不提交到Git
3. **脱敏显示**：只显示前8位和后4位

### 配置生效

1. **立即生效**：保存后无需重启
2. **自动感知**：所有Agent自动使用新配置
3. **持久化存储**：重启后依然有效
