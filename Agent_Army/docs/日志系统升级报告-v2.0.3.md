## 🎯 使用场景

### 场景1：调试前台无反应

**问题**: 用户点击"开始分析"后前台无反应

**解决**:
```bash
# 查看日志
tail -f logs/agent-army.log

# 观察输出
- 如果没有"Starting Step 1"日志 → 前端事件未触发
- 如果有"Starting Step 1"但没有"Executing industry analysis" → 模块加载失败
- 如果有"Executing"但超时无完成 → 分析器卡死
- 如果有error日志 → 查看详细错误堆栈
```

### 场景2：性能分析

**问题**: 分析耗时过长

**解决**:
```bash
# 查看耗时日志
grep "completed" logs/agent-army.log | tail -10

# 分析输出
2026-03-21 11:30:45 [info] Industry analysis completed elapsed_time=44.2
2026-03-21 11:31:25 [info] Fundamental analysis completed elapsed_time=40.1
2026-03-21 11:31:30 [info] Report generation completed elapsed_time=5.2

# 定位瓶颈：产业链分析耗时最长（44.2秒）
```

### 场景3：错误追踪

**问题**: 分析失败，需要查看详细错误

**解决**:
```bash
# 查看错误日志
tail -f logs/error.log

# 或查看主日志中的error
grep '"level": "error"' logs/agent-army.log | tail -5 | jq .

# 输出示例
{
  "level": "error",
  "timestamp": "2026-03-21 11:31:05",
  "message": "Step 1 execution failed",
  "error": "Connection timeout",
  "traceback": "Traceback (most recent call last):\n  File ...",
  "stock_code": "601669"
}
```
