### 1. ✅ 使用新设计系统重建仪表板


### 2. ✅ 统一卡片布局和指标展示

**实现的组件**：
1. **统计卡片** (`render_stat_card`)
   - 统一的布局和样式
   - 支持自定义颜色、图标、数值、趋势
   - 左边框 + 背景色 + 阴影效果

2. **新闻卡片** (`render_news_card`)
   - 根据影响类型自动着色
   - 时间 + 标题 + 关联股票
   - 统一的圆角和阴影

3. **军团卡片** (`render_army_card`)
   - 使用军团主题色
   - 星级完成度显示（⭐⭐⭐）
   - 当前状态说明

4. **任务列表项** (`render_task_item`)
   - 状态图标 + 徽章
   - 根据状态自动着色
   - 清晰的视觉层次

**布局改进**：
- 顶部统计卡片：4列网格，统一高度和样式
- 军团状态：3列网格，紧凑布局
- 任务/新闻：2列分栏，清晰分隔

### 3. ✅ 添加实时数据刷新交互

**实现的交互**：
1. **快速分析流程**
   - 输入框 + 大按钮
   - 点击后显示加载状态（`show_loading_overlay`）
   - 完成后显示Toast通知（`toast_success`）
   - 提示用户查看任务管理页面

2. **按钮状态反馈**
   - 主操作使用`type="primary"`
   - 按钮loading状态（spinner动画）
   - 成功/失败即时反馈

3. **Toast通知系统**
   - 成功提示（绿色✅）
   - 错误提示（红色❌）
   - 信息提示（蓝色ℹ️）

### 4. ✅ 优化加载状态和错误处理

**加载状态**：
- 初始加载：骨架屏（`show_skeleton_card`）
- 数据刷新：加载遮罩（`show_loading_overlay`）
- 长时间操作：进度条（`show_progress_bar`）

**错误处理**：
- 数据加载失败：错误卡片（`show_error_card`）
- 空数据：空状态提示（`show_empty_state`）
- 网络错误：重试按钮

**用户反馈**：
- 操作成功：Toast通知
- 操作失败：错误提示 + 恢复操作
- 操作中：loading状态
