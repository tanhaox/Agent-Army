## 🚀 Phase 4 详细任务

### 任务 4.1: Agent状态页面扁平化 (1天)

**优先级**: 🔴 高
**文件**: `src/core/pages_v2/agent_status.py` 和 `agent_status_optimized.py`

#### 现状问题

1. **层级过深**
   - ❌ 使用7个标签页嵌套
   - ❌ 信息分散在多个层级
   - ❌ 用户需要多次点击才能看到关键信息

2. **视觉不统一**
   - ❌ 没有完全使用Phase 1设计系统
   - ❌ 混用原生Streamlit组件
   - ❌ 颜色、间距不一致

3. **信息密度问题**
   - ❌ 卡片信息过载
   - ❌ 缺少信息层次
   - ❌ 关键信息不突出

#### 设计方案

**扁平化结构**:
```

│  │ [展开▶]  │ │ [展开▶]  │ │ [展开▶]  │           │

│  │🎯 目标预测│ │⚡ 策略执行│ │✅ 结果验证│           │
│  │ 5个Agent │ │ 5个Agent │ │ 5个Agent │           │
```

#### 实施步骤

1. **合并两个版本**
   - 合并 `agent_status.py` 和 `agent_status_optimized.py`
   - 保留优化版的性能特性
   - 应用Phase 1设计系统

2. **扁平化标签页结构**
   - 移除深层嵌套的标签页
   - 使用展开/折叠替代标签页
   - 一屏展示更多内容

3. **统一设计风格**
   - 使用 `DesignTokens.Colors` 统一颜色
   - 使用 `DesignTokens.Typography` 统一字体
   - 使用 `DesignTokens.Spacing` 统一间距
   - 应用全局样式系统

4. **优化卡片设计**
   - 简化Agent卡片信息
   - 突出关键指标（状态、评分）
   - 使用军团主题色
   - 添加悬停效果

5. **改善交互**
   - 展开/折叠军团详情
   - 快速筛选Agent状态
   - 实时刷新状态
   - 性能监控面板（可选）

#### 验收标准

- [ ] 页面加载时间 < 1秒
- [ ] 一屏展示24个Agent概览
- [ ] 所有颜色使用DesignTokens
- [ ] 所有组件统一样式
- [ ] 展开/折叠功能正常
- [ ] 移动端适配正常
