**功能版本**: v2.1 新增

**状态**: ✅ 已完成

## 🎯 功能说明

**问题**: 之前只能输入6位数字股票代码，不方便记忆
**解决**: 现在支持**股票名称、拼音缩写、股票代码**三种输入方式

---

## ✨ 支持的输入格式

### 1️⃣ 股票代码（原有方式）
```
600519  → 贵州茅台
000858  → 五粮液
002594  → 比亚迪
```

### 2️⃣ 股票名称（新增）⭐
```
贵州茅台  → 600519
五粮液    → 000858
比亚迪    → 002594
中国平安  → 601318
```

### 3️⃣ 拼音缩写（新增）⭐
```
GZMT    → 600519 (贵州茅台)
WLY     → 000858 (五粮液)
BYD     → 002594 (比亚迪)
ZGPA    → 601318 (中国平安)
```

### 4️⃣ 模糊匹配（新增）
```
茅台    → 600519 (贵州茅台)
平安    → 601318 (中国平安)
比亚迪   → 002594 (完整匹配)
```

## 🚀 使用方法

### 在任务管理页面

1. 进入"📋 任务管理"
2. 选择"📊 投资分析"
3. 在"股票代码/名称"输入框中：
   - 输入代码：`600519`
   - 或名称：`贵州茅台`
   - 或拼音：`GZMT`
4. 系统自动识别并显示：
   ```
   ✅ 已识别: 600519 - 贵州茅台
   ```
5. 点击"🚀 创建任务"

## 🔧 技术实现

### 核心文件
```
src/core/utils/stock_code_resolver.py
```

### 核心类
```python
class StockCodeResolver:
    def resolve(input_str: str) -> Optional[str]
    def get_stock_name(code: str) -> Optional[str]
    def search(keyword: str) -> List[Dict[str, str]]
```

### 解析逻辑
1. 检查是否为6位数字（股票代码）
2. 检查是否为已知股票名称
3. 检查模糊匹配（部分名称）
4. 检查拼音缩写
5. 拼音首字母匹配
