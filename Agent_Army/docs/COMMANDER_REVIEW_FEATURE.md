## 🎯 功能概述

**用户需求**: "Commander Agent职责是报告汇总和质量把关，他的给我的汇报在页面中如何体现？"

**解决方案**: 在"报告查看"页面添加**Commander审核状态**和**汇总报告**功能，让用户清楚看到Commander的工作成果。

## ✅ 新增功能

### 1. 投资分析报告 - Commander审核状态 ⭐

**位置**: 报告查看 → 投资分析报告 → 选择报告

**显示内容**:

#### 审核状态卡片

| 状态 | 图标 | 说明 |
|------|------|------|
| **✅ 已通过** | ✅ | 质量评分: XX分 |
| **❌ 已打回** | ❌ | 需重做 |
| **⏳ 待审核** | ⏳ | 等待Commander审核 |

#### 审核信息

- **审核时间**: Commander审核的具体时间
- **审核人**: Commander Agent（显示职责）
- **质量评分**: 0-100分（70分以上通过）
- **审核意见**: Commander的详细评价

#### 审核通过示例

```
✅ 审核通过
质量评分: 85分

🕐 审核时间: 2026-03-14 10:30:00

🎖️ 审核人: Commander Agent

✅ Commander意见: 报告质量合格，予以通过
```

#### 审核打回示例

```
❌ 已打回
需重做

❌ 拒绝原因: 分析内容过短，不够详细

⚠️ 已重试次数: 2/3

（如果达到3次）
⚠️ 已达最大重试次数，已通知HR Agent介入
```

## 🔍 质量检查标准

Commander Agent使用以下标准检查报告质量：

### 1. 完整度检查（20分/项）

```python
required_fields = ["stock_code", "analysis", "recommendation", "timestamp"]
for field in required_fields:
    if field not in report:
        issues.append(f"缺少必要字段：{field}")
        quality_score -= 20
```

### 2. 专业度检查（15分）

```python
if len(analysis) < 100:
    issues.append("分析内容过短，不够详细")
    quality_score -= 15
```

### 3. 准确度检查（25分）

```python
if agent_avg_accuracy < 70%:
    issues.append(f"该AI历史准确率过低：{avg_accuracy:.1f}%")
    quality_score -= 25
```

### 4. 建议合理性（20分）

```python
if recommendation not in ["BUY", "SELL", "HOLD", "STRONG_BUY"]:
    issues.append(f"投资建议不合规：{recommendation}")
    quality_score -= 20
```

### 通过标准

- **质量评分**: ≥ 70分
- **问题数量**: 0个

## 🔄 工作流程

### 正常流程

```
1. 业务Agent生成报告
   ↓
2. Commander审核报告
   - 检查完整度
   - 检查专业度
   - 检查准确度
   - 检查建议合理性
   ↓
3. 质量评分 ≥ 70分？
   - ✅ 是 → 通过审核
   - ❌ 否 → 打回去重做
   ↓
4. 用户查看报告
   - 看到审核状态
   - 看到质量评分
   - 看到Commander意见
```

### 打回流程

```
1. Commander打回报告
   ↓
2. 重试次数 +1
   ↓
3. 重试次数 < 3？
   - ✅ 是 → 业务Agent重新生成
   - ❌ 否 → 调用HR Agent介入
   ↓
4. HR优化业务Agent
   ↓
5. 重新生成报告
```
