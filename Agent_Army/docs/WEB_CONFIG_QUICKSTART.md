# 🚀 Web配置接口 - 快速参考卡片

---

## 📍 访问路径

```
Web界面 → ⚙️ 系统配置 → 🔑 API配置管理
```

---

## 🎯 三步配置API

### 1️⃣ 输入密钥
```
展开API卡片（如：🤖 智谱AI）
  ↓
在密码框中输入API密钥
```

### 2️⃣ 测试连接
```
点击"🔍 测试连接"
  ↓
验证密钥是否有效
```

### 3️⃣ 保存配置
```
点击"💾 保存配置"
  ↓
配置自动生效（无需重启）
```

## 🔧 支持的API

| API | 状态 | 用途 | 获取地址 |
|-----|------|------|----------|
| **智谱AI** | 必需 | 日常分析、搜索 | https://open.bigmodel.cn/ |
| **Tushare** | 必需 | 财务数据、行情 | https://tushare.pro/ |
| **DeepSeek** | 可选 | 基准测试 | https://platform.deepseek.com/ |
| **OpenAI** | 可选 | 关键决策 | https://platform.openai.com/ |

## 📊 切换数据源优先级

### 访问路径
```
⚙️ 系统配置 → 📊 数据源管理
```

### 配置方式
```
数据源1（优先级1）→ 首选
数据源2（优先级2）→ 备选
数据源3（优先级3）→ 兜底
```

### 自动切换机制
```
优先级1失败 → 自动尝试优先级2 → 自动尝试优先级3
```

## 💡 使用场景

### 场景1：首次配置
```
1. 获取API密钥（从智谱AI、Tushare官网）
2. 进入Web配置界面
3. 输入密钥 → 测试 → 保存
4. 开始使用
```

### 场景2：切换数据源
```
1. Tushare配额用完
2. 进入数据源管理
3. 将东方财富设为优先级1
4. 保存配置
```

### 场景3：验证配置
```
1. 进入测试工具
2. 点击"测试所有API连接"
3. 查看哪些API已配置
```
