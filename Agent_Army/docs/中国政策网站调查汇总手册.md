### 1.3 使用建议

#### 核心关注网站（每日必看）
1. **中国政府网** - 国务院重大决策部署第一时间发布
2. **国务院政策文件库** - 政策检索和归档查询
3. **国家发改委** - 产业政策风向标
4. **财政部** - 财政政策动向
5. **中国人民银行** - 货币政策和流动性
6. **中国证监会** - 资本市场监管政策

#### 使用技巧
- 设置网站RSS订阅或邮件提醒功能
- 重点关注"政策解读"栏目，理解政策意图
- 关注"新闻发布会"实录，获取政策背景
- 使用政策文件库的检索功能，按行业/时间筛选

## 使用指南总结

### 一、政策跟踪流程
1. **源头获取**：国务院/各部委官网获取原始政策
2. **专业解读**：财经媒体/研报平台获取深度分析
3. **市场反应**：财经门户/社区了解市场情绪
4. **公司公告**：巨潮资讯网查看相关公司披露

### 二、信息筛选原则
1. **权威性优先**：政府官网 > 监管机构 > 法定媒体 > 商业媒体
2. **时效性优先**：快讯平台用于盘中，深度分析用于盘后
3. **交叉验证**：重要信息需多方来源确认

### 三、风险提示
1. 商业媒体观点仅供参考，不构成投资建议
2. 社区讨论存在噪音，需独立判断
3. 政策解读以官方发布为准
