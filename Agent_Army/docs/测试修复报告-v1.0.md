### 2. PositionManagementAI kwargs提取bug

**问题描述**:
```python
# 错误代码
async def analyze(self, stock_code: str, **kwargs):
    self.logger.info(extra={
        "current_price": current_price,  # ❌ NameError
        "total_capital": total_capital,
        "risk_tolerance": risk_tolerance
    })
```

**根本原因**: 参数通过 `**kwargs` 传递，但代码直接引用变量名，导致 `NameError`

**修复方案**:
```python
# 正确代码
async def analyze(self, stock_code: str, **kwargs):
    # 从kwargs中提取参数
    current_price = kwargs.get('current_price')
    total_capital = kwargs.get('total_capital', 1000000)
    risk_tolerance = kwargs.get('risk_tolerance', '中等')

    self.logger.info(extra={
        "current_price": current_price,  # ✅
        "total_capital": total_capital,
        "risk_tolerance": risk_tolerance
    })
```

**影响文件**:
- `src/agents/business/strategy/position_management_ai.py`
