## 💡 技术实现

### 状态检查机制
```python
# 1. 初始化检查
try:
    tool = NewsTool()
    st.success("✅ 正常")
except Exception as e:
    st.error("❌ 异常")

# 2. API连接测试
from src.core.tools import LLMTool
tool = LLMTool()
st.info("✅ 连接正常")

# 3. 密钥脱敏显示
key = os.getenv("ZHIPU_API_KEY", "")
if key:
    st.caption(f"密钥: {key[:8]}...{key[-4:]}")
```

### 数据展示
- **实时性**: 每次刷新页面重新检查
- **脱敏显示**: 密钥只显示前8位和后4位
- **错误捕获**: 显示异常信息前30个字符
