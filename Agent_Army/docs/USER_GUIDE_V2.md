## 🚀 快速开始

### 环境要求

- Python 3.8+
- Windows/macOS/Linux
- 4GB+ 内存

### 安装步骤

1. **克隆项目**
```bash
cd c:/AI-Agent-Local/Agent_Army
```

2. **安装依赖**
```bash
pip install -r requirements.txt
```

3. **启动应用**
```bash
# Windows
run_web_v2.bat

# macOS/Linux
streamlit run src/core/web_app_v2_final.py
```

4. **访问应用**
```
http://localhost:8501
```

## ❓ 常见问题

### Q1: 如何更新Agent状态？

**A**: Agent状态会自动更新，刷新页面即可查看最新状态。

### Q2: 任务执行需要多长时间？

**A**:
- 快速分析: ~30秒
- 标准分析: ~1分钟
- 深度分析: ~3分钟

### Q3: 如何导出分析报告？

**A**:
1. 进入【分析报告】页面
2. 选择报告类型
3. 点击【导出PDF】或【导出Excel】

### Q4: K线图支持哪些技术指标？

**A**:
- MA5/10/20 (均线)
- MACD (指数平滑异同移动平均线)
- RSI (相对强弱指标)
- Bollinger Bands (布林带)

### Q5: 如何添加自定义Agent？

**A**: 当前版本暂不支持，计划在v3.0中添加。

### Q6: 数据更新频率？

**A**:
- 新闻数据: 实时
- 行情数据: 日线
- 财务数据: 季度

### Q7: 如何清除缓存？

**A**:
1. 进入【系统配置】页面
2. 切换到【系统设置】标签页
3. 点击【清除缓存】

## 💡 最佳实践

### 1. 任务创建

**建议**:
- 初次使用选择"标准分析"
- 熟悉后选择"深度分析"
- 批量分析使用"快速分析"

### 2. Agent选择

**全量分析** (24个Agent):
- 适合：深度研究
- 时间：~3分钟
- 全面性：⭐⭐⭐⭐⭐

**产业分析** (5个Agent):
- 适合：行业研究
- 时间：~1分钟
- 全面性：⭐⭐⭐⭐

**热点捕捉** (4个Agent):
- 适合：短线交易
- 时间：~30秒
- 全面性：⭐⭐⭐

**自定义**:
- 适合：特定需求
- 时间：取决于选择
- 全面性：⭐⭐⭐⭐

### 3. 风险控制

**建议**:
- 分散投资（不超过10只股票）
- 单只股票不超过20%
- 关注风险指标
- 设置止损位

### 4. 数据导出

**场景选择**:
- 正式报告: 导出PDF
- 数据分析: 导出Excel
- 快速分享: 使用分享链接
