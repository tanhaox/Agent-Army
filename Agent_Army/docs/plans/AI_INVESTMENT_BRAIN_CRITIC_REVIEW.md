### 问题4：缺少决策冲突解决规则

**问题**：6维度可能给出矛盾信号，缺少明确的冲突解决规则

**新增**：决策优先级

```
## 决策优先级

当6维度给出矛盾信号时，按以下优先级决策：

1. **割肉价（止损线）** - 最高优先级，必须遵守
2. **基本面** - 通过筛选（PB<1, ROE>10%, 负债率<60%）
3. **技术面** - 择时（突破支撑位、成交量放大）
4. **资金面** - 确认（主力资金流入）
5. **政策面** - 加权（政策支持提高权重10%）
6. **历史节点** - 参考（不作为主要决策依据）

**冲突示例**：
- 基本面好 + 技术面差 → 等待技术面改善
- 基本面差 + 技术面好 → 不参与（基本面是底线）
- 政策支持 + 资金流出 → 谨慎参与（降低仓位）
```
