## 🔄 工作流程

### Phase 1 投资分析流程

```
用户输入: 股票代码 (如 600519)
    ↓
[1] 产业链分析AI
    ├─ 分析行业定位
    ├─ 评估产业周期
    └─ 识别增长驱动因素
    ↓
[2] 基本面分析AI
    ├─ 财务数据分析
    ├─ 盈利能力评估
    ├─ 成长性分析
    └─ 偿债能力检查
    ↓
[3] 报告生成器
    ├─ 综合评分 (产业40% + 基本面60%)
    ├─ 投资评级
    ├─ 仓位建议
    └─ 风险提示
    ↓
输出: 投资分析报告 (JSON)
```
