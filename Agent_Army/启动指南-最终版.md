## 🚀 推荐启动方式（按优先级）

### 方式 1：PowerShell 启动（最推荐）⭐

**特点**：最可靠，有完整的错误提示，窗口不会关闭

**运行方法**：
1. 双击：`start_ps1.bat`
2. 或右键点击 `start_web.ps1` → 使用 PowerShell 运行

**优势**：
- ✅ 详细的启动日志
- ✅ 完整的错误检查
- ✅ 窗口不会关闭
- ✅ 彩色输出

---

### 方式 2：新窗口启动（推荐）⭐

**特点**：在新窗口中启动服务，原窗口显示提示

**运行方法**：
- 双击：`start_new_window.bat`

**优势**：
- ✅ 服务在独立窗口运行
- ✅ 原窗口显示访问地址
- ✅ 自动打开浏览器

---

### 方式 3：调试模式（用于排错）

**特点**：显示详细的启动信息

**运行方法**：
- 双击：`start_debug.bat`

**优势**：
- ✅ 显示每一步的执行结果
- ✅ 完整的错误信息
- ✅ 窗口保持打开

---

### 方式 4：手动启动（最灵活）

**适合**：开发调试

**方法 1 - CMD**：
```batch
cd C:\AI-Agent-Local\Agent_Army
streamlit run web_app_v2.py
```

**方法 2 - PowerShell**：
```powershell
cd C:\AI-Agent-Local\Agent_Army
python -m streamlit run web_app_v2.py
```

**优势**：
- ✅ 看到所有日志输出
- ✅ 可以手动调试
- ✅ 灵活控制

## 🔍 常见问题

### Q1: 双击后窗口一闪就没了

**A**: 使用 `start_ps1.bat` 或 `start_debug.bat`，这两个脚本窗口不会关闭

### Q2: 提示找不到 Python

**A**:
1. 确认 Python 已安装
2. 检查环境变量 PATH
3. 或使用完整路径：`C:\Python313\python.exe`

### Q3: 提示找不到 streamlit

**A**:
```bash
pip install streamlit
```

### Q4: 端口 8501 被占用

**A**:
```bash
# 方法1: 使用其他端口
streamlit run web_app_v2.py --server.port 8502

# 方法2: 关闭占用进程
netstat -ano | findstr :8501
taskkill /F /PID <进程ID>
```

### Q5: 模块导入失败

**A**:
1. 确认在正确的目录：`C:\AI-Agent-Local\Agent_Army`
2. 运行 `python test_imports.py` 测试
3. 检查是否有依赖缺失

## 🎯 推荐流程

### 第一次使用

1. 运行诊断：`python diagnose.py`
2. 测试导入：`python test_imports.py`
3. 启动服务：双击 `start_ps1.bat`
4. 访问：http://localhost:8501

直接双击：`start_ps1.bat`

### 开发调试

使用 CMD 或 PowerShell 手动启动，可以看到所有日志
