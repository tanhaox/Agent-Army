## 📋 测试前准备

### 环境检查
- [ ] Python环境正常（python --version）

- [ ] 配置文件存在（config目录）
- [ ] 日志目录可写（logs目录）

### 测试数据准备
- [ ] 测试股票代码：000001（平安银行）
- [ ] 测试股票代码：600519（贵州茅台）

## 🚀 测试执行

### 第1部分：应用启动测试 (1分钟)

#### 步骤1：启动应用
```
运行: start_ps1.bat
```

**检查项**:
- [ ] PowerShell窗口正常打开
- [ ] Python版本信息显示正确
- [ ] Streamlit启动信息显示
- [ ] 无ERROR级别日志
- [ ] 浏览器自动打开（或手动访问http://localhost:8501）

**通过标准**: 应用正常启动，无严重错误

---

#### 步骤2：页面加载
**检查项**:
- [ ] 页面在30秒内完成加载
- [ ] 页面标题显示正确："Agent Army v2.0"
- [ ] 左侧导航栏显示完整（8个菜单项）
- [ ] 主页内容正常显示
- [ ] 无JavaScript控制台错误

**通过标准**: 页面加载正常，布局完整

---

### 第2部分：页面导航测试 (2分钟)

#### 测试所有页面可访问性

**测试步骤**:
依次点击左侧导航栏的每个菜单项

| 页面 | 菜单文字 | 检查项 | 状态 |
|------|----------|--------|------|
| 1 | 🏠 主页 | 标题显示、统计卡片、快速操作 | [ ] |
| 2 | 🤖 Agent状态 | 6大军团卡片、展开/折叠功能 | [ ] |
| 3 | 📋 任务管理 | 任务列表、筛选器、新建按钮 | [ ] |
| 4 | 📊 分析报告 | 股票代码输入、报告类型选择 | [ ] |
| 5 | 💹 投资组合 | 持仓列表、收益统计 | [ ] |
| 6 | 🌐 市场监控 | 涨跌幅排行、成交量统计 | [ ] |
| 7 | ⚙️ 系统配置 | API配置、Agent配置 | [ ] |
| 8 | 📖 导航指南 | 快速开始、功能说明、FAQ | [ ] |

**通过标准**: 所有页面可以正常访问，无404或500错误

---

### 第3部分：核心功能测试 (2分钟)

#### 测试1: Agent状态页面
**操作步骤**:
1. 点击"🤖 Agent状态"
2. 查看6大军团卡片
3. 点击某个军团的"展开"按钮
4. 查看Agent详情

**检查项**:
- [ ] 6大军团卡片全部显示
- [ ] 军团主题色正确（产业蓝、热点橙、个股绿、目标黄、策略紫、验证青）
- [ ] 展开/折叠功能正常
- [ ] Agent状态显示（待命/运行中/已完成）
- [ ] 无数据显示"暂无数据"

**通过标准**: Agent状态显示完整，交互正常

---

#### 测试2: 任务管理页面
**操作步骤**:
1. 点击"📋 任务管理"
2. 查看任务列表（如果有）
3. 尝试使用筛选器
4. 点击"➕ 新建任务"按钮（但不提交）

**检查项**:
- [ ] 任务卡片布局正常
- [ ] 状态筛选器可用
- [ ] 类型筛选器可用
- [ ] 进度条显示正确
- [ ] 新建任务对话框弹出

**通过标准**: 任务管理功能正常

---

#### 测试3: 分析报告页面
**操作步骤**:
1. 点击"📊 分析报告"
2. 输入股票代码：000001
3. 选择报告类型：综合分析
4. 点击"生成报告"按钮

**检查项**:
- [ ] 股票代码输入框正常
- [ ] 报告类型选择器正常
- [ ] 生成按钮可点击
- [ ] 显示"生成中..."提示
- [ ] 报告内容显示（即使数据不完整）

**通过标准**: 报告生成流程正常

---

#### 测试4: 系统配置页面

1. 点击"⚙️ 系统配置"

**检查项**:
- [ ] API配置项显示完整
- [ ] Agent配置项显示完整
- [ ] 配置输入框可编辑
- [ ] 保存按钮存在
- [ ] 测试连接按钮存在

**通过标准**: 配置页面功能正常

---

### 第4部分：设计规范验证 (1分钟)

#### 视觉一致性检查

**检查项**:
- [ ] 所有页面使用相同的颜色主题
- [ ] 标题字体大小一致（H1, H2, H3）
- [ ] 卡片圆角统一（使用Design Tokens）
- [ ] 间距统一（padding, margin）
- [ ] 按钮样式一致
- [ ] 图标风格一致

**通过标准**: 视觉风格统一，符合设计规范

---

#### 响应式检查
**操作步骤**:
1. 调整浏览器窗口宽度
2. 观察页面布局变化

**检查项**:
- [ ] 窗口缩小时，布局适应
- [ ] 卡片自动换行
- [ ] 文字不溢出
- [ ] 按钮可点击

**通过标准**: 布局适应不同屏幕尺寸

---

### 第5部分：错误处理测试 (1分钟)

#### 测试异常输入

**测试场景**:
1. 在股票代码输入框输入：空的、错误的代码
2. 快速连续点击按钮
3. 在网络断开时生成报告（可选）

**检查项**:
- [ ] 空输入有错误提示
- [ ] 错误格式有错误提示
- [ ] 重复点击被正确处理
- [ ] 错误信息友好、清晰

**通过标准**: 异常情况有合适的错误提示

### 标准流程
1. **准备阶段** (5分钟)
   - 环境检查
   - 测试数据准备

2. **执行阶段** (5分钟)
   - 运行自动化测试
   - 执行手动测试清单

3. **报告阶段** (5分钟)
   - 记录测试结果
   - 填写问题清单
