## 📋 测试概述

### 测试目标

- ✅ 模块导入测试
- ✅ Design Tokens系统测试
- ✅ 页面渲染测试
- ✅ Agent初始化测试
- ✅ 数据源连接测试
- ✅ API配置测试
- ✅ 基本工作流测试

### 执行时间
- 自动化测试: ~2分钟
- 手动测试: ~5分钟
- **总计**: ~7分钟

## 🤖 自动化测试

### 运行命令

```bash
# 方式1：运行完整冒烟测试
python tests/smoke_test.py

# 方式2：运行特定测试套件
python tests/smoke_test.py --suite import
python tests/smoke_test.py --suite design-tokens
python tests/smoke_test.py --suite agents
python tests/smoke_test.py --suite all

# 方式3：生成详细报告
python tests/smoke_test.py --report --output smoke_test_report.html
```

## 🔄 CI/CD集成

### GitHub Actions示例

```yaml
name: Smoke Test

on:
  push:
    branches: [ master, develop ]
  pull_request:
    branches: [ master ]

jobs:
  smoke-test:
    runs-on: ubuntu-latest
    steps:
    - uses: actions/checkout@v2

    - name: Set up Python
      uses: actions/setup-python@v2
      with:
        python-version: '3.10'

    - name: Install dependencies
      run: |
        pip install -r requirements.txt

    - name: Run Smoke Test
      run: |
        python tests/smoke_test.py --report --output smoke_test_report.html

    - name: Upload Report
      uses: actions/upload-artifact@v2
      with:
        name: smoke-test-report
        path: smoke_test_report.html
```

## 📝 测试最佳实践

### 1. 测试时机
- ✅ 每次代码提交后
- ✅ 每次功能升级后
- ✅ 每次bug修复后
- ✅ 每次发布前

### 2. 测试频率
- 日常开发: 每天至少1次
- 发布前: 必须执行完整测试
- 紧急修复: 至少执行关键测试

### 3. 失败处理
- 测试失败时，必须修复后才能合并
- 记录所有失败项到Issue追踪系统
- 分析失败原因，改进代码质量

### 4. 持续改进
- 定期更新测试用例
- 添加新功能的测试
- 移除过时的测试
- 优化测试执行时间
