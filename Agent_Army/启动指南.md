# Agent Army v2.0 - 启动指南

## 问题：程序闪退

如果 `start_web.bat` 启动后闪退，请尝试以下方法：

---

## ✅ 推荐方法 1：使用简化启动脚本

```batch
start_simple.bat
```

这个脚本最简单，直接启动 Streamlit。

---

## ✅ 推荐方法 2：手动启动（最可靠）

打开命令提示符（CMD），执行：

```batch
cd C:\AI-Agent-Local\Agent_Army
python -m streamlit run web_app_v2.py
```

或者使用 PowerShell：

```powershell
cd C:\AI-Agent-Local\Agent_Army
python -m streamlit run web_app_v2.py
```

---

## ✅ 推荐方法 3：使用 Python 启动脚本

```batch
start_web_safe.bat
```

这个脚本使用 Python 方式启动，更可靠。

---

## 📋 启动前检查

如果上述方法都失败，请运行诊断脚本：

```bash
python diagnose.py
```

这会检查：
- Python 版本
- Streamlit 版本
- 关键文件是否存在
- 模块导入是否正常

---

## 🔧 常见问题

### 问题 1：找不到 Python

**错误**：`'python' 不是内部或外部命令`

**解决**：
1. 确认 Python 已安装
2. 将 Python 添加到系统 PATH
3. 或使用完整路径：`C:\Python313\python.exe`

### 问题 2：找不到 Streamlit

**错误**：`No module named streamlit`

**解决**：
```bash
pip install streamlit
```

### 问题 3：端口 8501 被占用

**错误**：`Address already in use`

**解决**：
1. 关闭占用端口的程序
2. 或使用其他端口：
```bash
python -m streamlit run web_app_v2.py --server.port 8502
```

### 问题 4：模块导入失败

**错误**：`ModuleNotFoundError: No module named 'src'`

**解决**：
1. 确认在正确的目录：`C:\AI-Agent-Local\Agent_Army`
2. 不要在其他目录运行
