# 📚 Agent Army 使用示例

本目录包含Agent Army的完整使用示例。

## 📁 示例列表

### 基础示例

1. **[01_basic_analysis.py](01_basic_analysis.py)** - 基础股票分析
2. **[02_timing_judgment.py](02_timing_judgment.py)** - 时机判断
3. **[03_risk_management.py](03_risk_management.py)** - 风险管理

### 进阶示例

4. **[04_batch_analysis.py](04_batch_analysis.py)** - 批量分析股票池
5. **[05_full_workflow.py](05_full_workflow.py)** - 完整投资分析流程
6. **[06_parallel_analysis.py](06_parallel_analysis.py)** - 并行分析优化

### 专项示例

7. **[07_monitoring_system.py](07_monitoring_system.py)** - 监控系统
8. **[08_backtest_validation.py](08_backtest_validation.py)** - 回测验证
9. **[09_asset_allocation.py](09_asset_allocation.py)** - 资产配置

### 综合示例

10. **[10_comprehensive_demo.py](10_comprehensive_demo.py)** - 综合演示

## 🚀 快速开始

```bash
# 运行基础示例
python examples/01_basic_analysis.py

# 运行完整流程示例
python examples/05_full_workflow.py
```

## 📖 学习路径

1. **新手**: 从 `01_basic_analysis.py` 开始
2. **进阶**: 学习 `05_full_workflow.py` 和 `06_parallel_analysis.py`
3. **高级**: 研究 `10_comprehensive_demo.py`

## 💡 提示

- 所有示例都使用异步编程（async/await）
- 当前使用模拟数据，未来将接入真实数据源
- 可以根据需求修改参数和配置
