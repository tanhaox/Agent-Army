## API权限分析

根据Tushare官方文档，不同接口需要不同的权限等级：

| 接口 | 权限要求 | 当前状态 |
|------|---------|---------|
| stock_basic | 免费 | ✅ 可用 |
| daily_basic | 免费 | ⚠️ 待测试 |
| daily | 免费 | ✅ 可用 |
| moneyflow | 积分≥2000 | ❌ 权限不足 |
| top_list | 积分≥2000 | ❌ 权限不足 |
| announcement | 积分≥2000 | ❌ 权限不足/接口错误 |
