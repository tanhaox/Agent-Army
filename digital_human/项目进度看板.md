## 当前核心动作

```
每天:
  1. 写 / 找一条稿 (200-300 字财经主题)
  2. POST /api/articles → 改 raw_text
  3. POST /api/articles/{id}/rewrite → 拿 script_id
  4. IndexTTS2 /v1/tts 单次 → layer1 wav (10-15s)
  5. ComfyUI LTX23 (用 layer1 wav) → layer2 数字人 mp4
  6. script_text → layer3 (txt)
  7. script_text → HF render → layer4 hf mp4
  8. ↓
  9. 4 层产物丢剪映手动拼
```

### 1. 洗稿

```bash
ARTICLE_ID=$(curl -s -X POST http://127.0.0.1:54323/api/articles \
  -H "Content-Type: application/json" \
  -d '{"title":"...","raw_text":"..."}' | python -c "import json,sys; print(json.load(sys.stdin)['id'])")

# 触发洗稿
curl -X POST "http://127.0.0.1:54323/api/articles/$ARTICLE_ID/rewrite" \
  -H "Content-Type: application/json" -d '{}'

# 等 done，看 SSE
SCRIPT_ID=...  # rewrite_done 推送里有
```

### 2. 第 1 层（完整 wav）

```bash
curl -X POST http://127.0.0.1:7862/v1/tts \
  -H "Content-Type: application/json" \
  -d "{\"text\":\"...\",\"spk_audio_prompt\":\"老陈_沉稳_30s.wav\",\"master_style\":\"calm\"}" \
  --output layer1.wav
```

### 3. 第 2 层（数字人视频）

```bash
VIDEO_ID=$(curl -s -X POST http://127.0.0.1:54323/api/dhv/videos \

```

### 4. 第 4 层（HF 视频）

```bash
npx hyperframes render . -o layer4.mp4
```
