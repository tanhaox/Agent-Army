## 十、核心设计原则：人类可观测性（2026-07-25 拍板）

**用户原话**："这个项目没开发完，还在完善，很多额外的开发其实都是因为，我是人类，我不知道后台在跑什么。"

**原则**：项目核心设计 = AI 跑 + **人类能看见后台在做什么**。

**执行硬规则**：
- **永不许绕过用户的 UI 直接调 API**（包括 Fish Speech / ComfyUI / DeepSeek / 任何外部服务）
- 所有交互从 UI 触发，让用户看见按钮、进度、结果、产物
- 如果某个功能 UI 里没有 = **未完成**，要补 UI，不能绕过
- 后台服务（54321 端口 web UI / Swagger / 数据库 / 输出目录 / 音色档案）都是为这条原则服务

**适用范围**：A 管线所有功能（角色生成 / TTS / 文案洗稿 / 视觉导演 / 视频合成 / 发布）/ 以及未来 B 管线解冻后同样适用。
