## 2. 套路配方（J2 直接可实现）

每条配方 = pyJianYingDraft 调用组合，`jy_effect_library` 按 ID 引用（catalog JSON 已含）：

| 配方名 | 组合 | 适用 slot |
|---|---|---|
| **R1 字幕浮现** | TextSegment + anim_in 向上滑动(500ms) + anim_out 渐隐(500ms)，花字"简约白色镂空" | 口播字幕逐句 |
| **R2 强调数字卡** | anim_in 放大(500ms) + video_effect 边缘发光/星火 | 数据/结论强调 |
| **R3 人像常驻** | 美颜组全套 + 暗角（15× 验证的口播标配） | host 出镜段 |
| **R4 冲击晃动** | 左右摇晃 + 轻微抖动 + 故障 II，转场闪黑/炫光 | 情绪高点/翻车段 |
| **R5 温暖讲述** | 光晕 + 丁达尔光线，转场叠化 | 背景/过渡段 |
| **R6 知识标注** | 贴纸三件套（白色光线+红色箭头+红圈），箭头 anim_in 渐显 | 指代/圈重点 |
| **R7 开场钩子** | 开幕动画大标题 + 星火/聚光灯（25期范式：复合片段+多层并行） | 首 8 秒 |
| **R8 错峰收尾** | 贴纸每 0.5s 递进入场（渐显 500ms）+ 字幕 5 层渐隐（25期结尾范式） | 结尾 20 秒 |

## 3. J2 落地路径

1. `jy_effect_library.py`：加载 `jy_effect_catalog.json`，提供 `apply_recipe(segment, recipe_id, **params)`，内部映射到 pyJianYingDraft 的 `add_animation / add_effect / add_transition / 贴纸` 调用（resource_id 硬编码自 catalog）
2. 导演规划：slot 输出新增 `effect_recipe` 字段（R1~R8），由 `_intent.py` 按段落情绪/功能自动建议（惊讶→R4、讲述→R5、数据→R2）
3. `jy_draft_service`（J1 的产物生成器）消费 recipe，产出带效果的完整草稿
4. 待补：`7416258989467374091` 的效果名与视觉（剪映里对照）；单发高级转场（粒子消散/水墨等）做成可选风格包
