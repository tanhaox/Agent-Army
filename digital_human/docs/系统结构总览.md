## 0. 这是什么

**数字人短视频生产流水线**（FastAPI 后端 + SQLite + 本地 GPU）。输入新闻/书/PPT → AI 洗稿/拆书 → TTS 配音 → 剪映草稿 → 人工精修导出。当前 4 条产线：**新闻线 / 拆书 / PPT 出片 / 导演(J线/HF)**。

## 1. 技术栈

- Python 3.11 + FastAPI + uvicorn（`run_web.py`，端口 54321）
- SQLite + SQLAlchemy（`data/pipeline.db`）
- LLM：DeepSeek（创作/洗稿，`config/app.yaml` deepseek）+ 本地 Gemma-31B（蒸馏/打标/合规，llama-server）+ Qwythos-9B（本地视觉）
- TTS：IndexTTS2（主，gpu_service_manager 托管 4090 自动拉起）
- 视频：ComfyUI LTX2.3（数字人）、HyperFrames（HF 视觉，CPU）
- 剪映草稿：pyJianYingDraft（J 线/PPT 出片）
- PPT 截图：Playwright + 系统 Chrome

## 2. 产线地图

```
新闻线: 文章 → 素材包(七层审计+智谱补搜) → 洗稿(laotan-tech/geo) → TTS → 导演 → 剪映草稿
拆书:   书 → L0蒸馏(两级) → facing(八面向) → 5步创作(自动填充+豆瓣真实反应) → 创作层+编辑层 → TTS → 剪映草稿
PPT:    上传pptx → 每页台词TTS → 元素级拆解(jy2) → 剪映多轨草稿
导演:   音频对齐 → slot规划 → broll/HF/host执行 → 合成 → 剪映草稿
```

## 4. 核心流程

### 新闻线（5 步）
文章 → 素材包(七层审计) → 洗稿(注入素材+伪评论) → 爆品改造(P2→P5) → TTS → 导演 → 剪映

### 拆书（L0 两级蒸馏 + 5 步自动填充 + 创作/编辑两层）
```
L0 第一层: reader章节块(元信息/排版强调§B§/注释/引用源头) → 自适应打包 → Gemma逐章提取
          → data/l0/{书名}/l0-chapter-v1.json
facing 第二层(八面向): kernel(内核) / units(三段结构) / quotes(金句分级) / cases(当代桥接)
          / compliance(tier) / readers(痛点) / hooks(开篇钩子) / relations(人物图谱+论证位置+作者意图)
建书: 【新书】只列全流程蒸馏完成的书(蒸馏txt+L0+全facing) → 豆瓣高赞短评/书评自动抓取(input_json.douban)
     → L0未就绪时后台补跑(轮询 /books/{id}/prep) → auto_fill(补全/合规/评论层/总纲)
逐集(创作层): 质量标准8条 + ⟦⟧原话标记 + relations人物图谱 + 豆瓣真实反应(共鸣/槽点)注入
     → 编辑层 editorial_pass(身份=审核编辑, 专职口语化, ⟦⟧/术语保护) → 人设注入(自称"静")
```
总纲三段结构：**E1 导读(含系列预告) → 中间拆解 → 末集落地(实操清单)**，集数按 units 自适应（4-8 集）。
源头书库：reference_library 聚合 L0 references → 选题池(下一批拆书候选) + 引用榜 + 每本书单体系。

### 统一合规入口（全系统）
`config/compliance_common.json`（6 类禁用词）→ `app/services/compliance.py`（build_redline_prompt 源头注入 + check_text 检查）→ 拆书 facing/逐集 + 新闻线洗稿模板自动注入。

## 6. 最近架构（08-23）

- **口播稿创作/编辑两层**：创作层（质量标准 8 条 + ⟦⟧ 原话标记）→ 编辑层 `editorial_pass`（"抖音口播稿审核编辑"身份，专职口语化，⟦⟧/术语保护）→ 人设注入（自称"静"非"静姐"）
- **facing relations 理解面向**（第 8 面向）：跨章人物图谱 + 概念论证位置（核心框架 vs 支撑）+ 作者意图；L0 是提取层，理解在面向层
- **豆瓣爬虫**（douban.py）：建书自动抓高赞短评（情绪/共识）+ 书评正文（笔记/深度）→ 逐集注入真实共鸣 + 真人槽点（康复太快/投资房地产）
- **源头书库**：reference_library 聚合 L0 references → 选题池（下一批拆书候选，电子书线落地）+ 引用榜 + 每本书单体系
- **建书流程**：【新书】只列全流程蒸馏完成的书；L0 未就绪后台补跑（轮询 `/books/{id}/prep`）；auto_fill 评论层 LLM 回退
- **成本**：一本书全走 deepseek v4-pro 约 3~6.5 元（峰谷定价）；现状（L0/facing 本地 Gemma）约 1.5~3 元/本
- 08-22：L0 两级蒸馏 + 产线自动化 + 总纲三段结构 + 统一禁用词（详见 CHANGELOG.md）
