## 🔄 工作流程

```
用户: "帮我修复订单匹配的bug"
   ↓
AI 检测到关键词: "bug"
   ↓
AI: "老板，检测到关键词'bug'，我先为您备份一下代码..."
   ↓
[执行备份 - 2-3秒]
   ↓
AI: "✅ 备份完成！Commit: abc1234
     现在开始修复bug..."
   ↓
[执行任务]
```

---

## 💡 使用说明

### 自动触发（推荐）

正常对话即可，AI 会自动检测关键词：

```
✅ "优化一下这个函数"
✅ "修复这个bug"
✅ "添加新功能"
✅ "重构代码"
```

### 手动触发

如果需要手动备份，告诉 AI：

```
"先备份一下"
"备份当前状态"
"创建备份点"
```

---

## ⚡ 性能说明

- 备份速度: < 3 秒
- 冷却期: 60 秒（防止频繁备份）
- 备份范围: 整个项目（排除 .gitignore 中的文件）

---

## 🛡️ 安全保障

- ✅ 所有修改都会在 Git 中记录
- ✅ 可以随时回滚到任意备份点
- ✅ 备份失败时不会执行任务
