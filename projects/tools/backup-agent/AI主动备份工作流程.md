# AI 主动备份 - 工作流程

## 📋 概述

AI 主动备份功能让 Claude Code 可以在检测到关键词时自动触发备份，确保代码安全。

---

## 🔄 工作流程

### 标准流程

```
用户: "帮我修复订单匹配的bug"
   ↓
AI 检测到关键词: "bug"
   ↓
AI: "好的老板！检测到关键词'bug'，我先为您备份一下代码..."
   ↓
[执行备份 - 2-3秒]
   ↓
AI: "✅ 备份完成！Commit: 291e985
     现在开始修复订单匹配的bug..."
   ↓
[执行任务]
```

## 🔧 故障排除

### 问题：备份失败

**原因**：
- 文件路径过长（如 node_modules）
- Windows 保留文件名（如 nul）

**解决**：
- 检查 [.gitignore](../../../.gitignore)
- 删除问题文件后重试

### 问题：备份较慢

**原因**：
- 修改文件较多
- Git 自动打包（gc）

**正常**：
- 首次备份可能较慢
- 后续备份 < 3 秒

## 🛡️ 安全保障

### 备份保护

- ✅ 所有修改都在 Git 中记录
- ✅ 可以回滚到任意备份点
- ✅ 备份失败不会执行任务

### 回滚方法

```bash
# 查看备份清单
python backup_agent.py --list

# 按 ID 回滚
python backup_agent.py --rollback 1

# 按时间回滚
python backup_agent.py --rollback "2026-02-27 02:31"

# 按关键词回滚
python backup_agent.py --rollback "bug关键词"
```
