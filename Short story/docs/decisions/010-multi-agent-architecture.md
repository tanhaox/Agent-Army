# 决策记录：多 Agent 架构

> **状态**：✅ 已确定
> **日期**：2026-07-08

---

## 🎯 决策摘要

采用**多 Agent 架构**而非**全局 Agent**：

> **"一个 Agent 干一件事，做到专精"**

| Agent | 职责 | 出现位置 |
|-------|------|---------|
| 档案 Agent | 引导填卡 | `chat-fill.html` |
| 写作 Agent | 辅助写作 | `write.html` |
| 审核 Agent | 挑刺找问题 | `audit.html` + 全局 |
| 建议 Agent | 主动建议 | 相关页面右下角 |

---

## 💬 用户洞察

> "**但是专注的我也需要。比如，在填写人物卡时，是不是可以搞一个专职的 agent？而写作是个专职的 agent？全局的我反倒觉得没这么重要。因为足够专精才可以。**"

**核心设计哲学**：
- ✅ **专精的 Agent > 全能 Agent**
- ✅ 每个 Agent 负责一个具体任务
- ✅ 写档案的 Agent 熟悉所有字段
- ✅ 写片段的 Agent 熟悉所有人物

---

## 🏗️ 4 个 Agent 详细设计

### Agent 1：档案 Agent（"档案小秘书"）

**位置**：`chat-fill.html`（已实现）

**专长**：
- 熟悉 13 维度所有字段
- 知道怎么问让作者思考更深入
- 不会问开放性问题（问得很具体）
- 引导作者思考不偏离主线

**职责**：
- 按 section 引导对话
- 提取结构化字段
- 自动填入档案

### Agent 2：写作 Agent（"写作伙伴"）

**位置**：`write.html` 右侧 AI 守护栏

**专长**：
- 声纹检查（对话是否符合人物性格）
- 设定一致性（不与已有设定矛盾）
- 情节建议（下一步可怎么写）
- 句式范例（提供类似风格的句子）

**职责**：
- 实时守护写作过程
- 检测到问题主动提醒
- 接受作者询问

**触发场景**：
- 每段保存时自动检测
- 作者点击"AI 建议"时主动建议

### Agent 3：审核 Agent（"挑剔编辑"）

**位置**：`audit.html` + 任何页面右下角

**专长**：
- 找伏笔遗忘（埋了没收）
- 找人物 OOC（性格不一致）
- 找设定矛盾（自相冲突）
- 评估节奏（太快/太慢）

**职责**：
- 沉淀审核（每 10-30 章）
- 主动挑刺
- 提供修改建议

### Agent 4：建议 Agent（"创意顾问"）

**位置**：所有相关页面右下角（不打扰）

**专长**：
- 伏笔建议（这个伏笔可以这样埋...）
- 反差建议（这里可以加强反差...）
- 节奏建议（这段话太口语...）

**职责**：
- 主动建议（不主动推送）
- 作者点击时再出现

## 📐 架构实现

### Phase 1：档案 Agent（已完成）
- `chat-fill.html` ✅
- 13 section × 5-8 问题 = 70 个引导问题
- 实时字段提取

### Phase 2：写作 Agent（核心需求）
- `write.html` 右侧 AI 守护栏增强
- 4 个守护能力：
  - 声纹检查
  - 设定一致性
  - 情节建议
  - 句式范例

### Phase 3：审核 Agent
- `audit.html` 增强
- 自动挑刺 + 报告

### Phase 4：建议 Agent
- 所有相关页面右下角"💡建议"按钮
- 主动建议 + 被动回答
