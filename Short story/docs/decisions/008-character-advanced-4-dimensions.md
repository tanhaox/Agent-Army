## 🎯 决策摘要

在原有 5 + 4 = 9 个 section 基础上，**新增 4 个高阶维度**：

```
原有结构：
├─ 基础层：基本信息、执念、声音指纹、人物关系
├─ 动力层：长线目标与阶段性任务
├─ 商业层：核心卖点/金手指、社交生态位
└─ 张力层：反差感与弱点

新增 4 个高阶维度：
├─ 10 核心伪装动机（动机闭环）     ← NEW
├─ 11 专属具象怪癖（记忆锚点）     ← NEW
├─ 12 环境博弈（不确定性互动）     ← NEW
└─ 13 动态人物弧光（成长轨迹）     ← NEW
```

## 💎 4 个新维度详解

### 维度 1：核心伪装动机（动机闭环）

**问题**：很多作者写"扮猪吃虎"或"腹黑智斗"时，把主角写成"天生爱算计、笑里藏刀"，读者觉得人设空洞。

**解法**：必须为主角的"伪装"或"反差"设计**明确的、让读者能共情的底层动机**。

**实战应用**：

| 角色 | 伪装 | 动机闭环 |
|------|------|---------|
| 宁毅 | 早期"咸鱼伪装" | 只想独善其身 → 苏檀儿被逼跳河（至亲受难）→ 撕下面具 |
| 许七安 | "吊儿郎当" | 身处体制内需要自保 → 面对底层百姓被屠戮时必须站出来 |

**关键**：只有理由够充分，逻辑够闭环，读者才会彻底代入主角的"腹黑"或"隐忍"行为。

### 维度 2：专属具象怪癖（记忆锚点）

**问题**：在"数据库写作"和"萌要素"盛行的网文时代，人物容易陷入标签化的同质竞争。

**解法**：为主角设计一个**无伤大雅、专属独特的具象怪癖**。它不冲突人设、不违和剧情，但能成为读者一眼难忘的视觉/行为标签。

**实战应用**：

| 角色 | 怪癖 |
|------|------|
| 许七安 | 思考案情时**敲桌子**或**抛铜钱** |
| 宁毅 | 极度愤怒前**整理袖口**，表现出极度的平静 |

**关键**：具体的视觉特征或习惯，比笼统的"聪明"、"冷酷"有效得多。

### 维度 3：环境博弈与"不确定性"互动（新网文特质）

**问题**：传统网文主角带有"天命在我"的自信，世界是升级踏脚石。新网文中，主角与世界关系发生质变。

**解法**：主角不再是绝对中心，他必须在一个充满混乱、诡异、随机或规则束缚的世界中**挣扎**。主角的成功是有代价和局限的。

**实战应用**：

```
传统网文：
  主角 → 升级 → 战胜世界

新网文：
  主角 + 规则 → 借力打力 → 在夹缝中破局
```

| 角色 | 环境博弈 |
|------|---------|
| 许七安 | 破案如神 + 朝堂党争倾轧 + 皇权猜忌 → 在规则夹缝中借力打力 |
| 宁毅 | 现代知识 + 古代权谋 → 每次破局都是规则套利 |

**关键**：要设定"世界规则如何压制主角"，而不是只设定"主角有多强"。

### 维度 4：动态的人物弧光（成长轨迹）

**问题**：执念是相对静态的，能连载几百万字的主角必须有**动态演变**。

**解法**：成长轨迹公式：
```
初始状态 → 遭遇事件打破日常 → 关键抉择 → 最终状态
```

**实战应用**：

**宁毅的弧光**（4 阶段）：
1. 现代金融巨鳄（冷漠）
2. 江宁赘婿（温和/出世）
3. 霖安城之变（绝望/弑君）
4. 华夏军统帅（入世/为生民立命）

**许七安的弧光**（3 阶段）：
1. 只想自保的底层捕快
2. 为家族洗冤
3. 为天下人拔刀（对抗体制）

**关键**：没有弧光的主角，写到两百万字就会变成毫无感情的"推土机"或"装逼机器"。

## 🎯 终极商业主角设定模型（13 维度）

| 层级 | 维度 | 来源 |
|------|------|------|
| **基础层** | 姓名、定位、出身、外貌、声音指纹、人物关系 | 严肃小说 |
| **动力层** | 执念（谎言与真理）、长线目标与阶段性任务 | 严肃+商业 |
| **商业层** | 核心卖点（金手指）、社交生态位（装逼舞台）| 商业网文 |
| **张力层** | 反差感与弱点、专属具象怪癖、核心伪装动机 | 🆕 高阶 |
| **深度层** | 环境博弈（与规则的不确定性互动）、动态人物弧光 | 🆕 高阶 |
