## 🏗️ v2 主导架构（最高纲领）

```
写作时 → writing 状态 → 单 Agent Ollama 本地（防胡写实时拦截）
       ↘ 严禁云端（4 道门禁全部 P0，ai_drafted 内容豁免部分门禁）

检视时 → reviewing 状态 → 多 Agent mmx-cli 云端并发
       ↘ 立项会 / 打磨 / 跨章审核 / 巡检（多 Agent 协作）

立项会 = 启动器（P10）：
  Step 1 完成后强制触发 → 多 Agent 协同审查 → 必须解决的冲突清单
  返设定时增量模式（Q30），不到位就别写

甘特图 6+ 泳池巡检（P11）：
  每 10 章一次 → 6 泳池并行（伏笔/人物弧光/物品/世界观/看点/关系）
```

## 🎯 核心决策一览（v2）

### 1. 状态切换（P15，最高纲领）

- ✅ **writing 状态**：仅本地 Ollama，4 门禁红警/警告
- ✅ **reviewing 状态**：本地优先 + 云端协同，自动降级回退
- ✅ **状态切换自动**：作者无需手动授权每章节

### 2. 立项会 = 启动器（P10）

- ✅ **强制触发**：Step 1 完成后自动
- ✅ **多 Agent 云端协同**（P14）：档案/世界观/人物/节奏 4 维度
- ✅ **输出冲突清单**：🔴 硬否决 / 🟠 必须修复 / 🟡 建议 / 🟢 已对齐
- ✅ **不合格就别写**：打磨不过则不开始

### 3. 甘特图 6+ 泳池巡检（P11）

- ✅ **每 10 章一次**
- ✅ **6 泳池并行**：伏笔 / 人物弧光 / 物品升级 / 世界观 / 看点 / 关系
- ✅ **本地按泳池 + 云端汇总**：单泳池 token 预算 4k

### 4. 4 道门禁全 P0 + 内容出处豁免（P13 + F6）

| 优先级 | 门禁 | 触发时机 | ai_drafted 是否豁免 |
|--------|------|---------|-------------------|
| 🔴 P0 | 防胡写 | writing 每段 | 🟢 豁免 |
| 🔴 P0 | 违规词 | 写作警告 / 发布前阻断 | ❌ 全检 |
| 🔴 P0 | 机械表达 | 段落规则 + 章节 Ollama | ❌ 全检 |
| 🔴 P0 | AI 味 | 每章末 + 立项会多 Agent | 🟢 豁免 |

### 5. 伏笔半自动闭环（F3）

- ✅ **作者主控**埋/收
- ✅ **AI 提议回收候选**（F2 + F4）
- ✅ **作者接受/拒绝**
- ✅ **误报反馈**回训练（P2）

### 6. Web spec + 数据契约（P5'）

- ✅ **21 Web 页面 = 规格说明书**
- ✅ **CLI 输出字段 ⊇ Web 字段**
- ✅ **contracts/*.yaml 数据契约必出**

## 📋 决策原则（v2 不变）

1. **作者主导** —— 作者仍是决策者
2. **简单可控** —— 优先选择简单方案
3. **可解释** —— 每个决策都能说出理由
4. **可回滚** —— 不好用能改（git 全保留）
5. **数据驱动** —— 设计基于实际场景
6. **决策修订** —— 走 `docs/DECISION_REVISION.md` 流程
