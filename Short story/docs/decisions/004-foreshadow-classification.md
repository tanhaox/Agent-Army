## 🎯 决策摘要

伏笔的载体分类从**一级**细化为**二级**：

```
一级：人 / 事 / 物
二级：
  人 → ⬆️ 出场 / ⬇️ 退场
  事 → ✅ 好事 / ❌ 坏事
  物 → ⬇️ 获得 / ⬆️ 损失
```

---

## 💬 讨论历程

### 用户洞察

> "载体类型的图标在'人事物'这个标签里，我觉得还可以再细分一下，例如二级或三级分类"

**原始想法**：
- 👤 人：出场还是退场？
- 📅 事：好事还是坏事？
- 🎁 物：获得还是损失？

### 进一步讨论

> "通过这个二三级的标注，其实可以更进一步地理解这件事，或者说这个小伏笔、大伏笔对整个故事的影响。"

**洞察**：
- 二级分类不是简单的"是/否"
- 而是**揭示故事走向**的标注
- 不同的二级 → 不同的故事影响

---

## ✅ 最终设计

### 二级分类完整列表

| 一级 | 二级 | 故事影响 | 图标 | 颜色 |
|------|------|---------|------|------|
| 👤 人 | ⬆️ 出场 | 引入新变量，关系网扩大 | 👤⬆️ | 🟢 绿 |
| 👤 人 | ⬇️ 退场 | 情感冲击，关系网缩小 | 👤⬇️ | 🔴 红 |
| 📅 事 | ✅ 好事 | 推进/解决，矛盾减少 | 📅✅ | 🟢 绿 |
| 📅 事 | ❌ 坏事 | 倒退/障碍，矛盾增加 | 📅❌ | 🔴 红 |
| 🎁 物 | ⬇️ 获得 | 增强能力/资源增加 | 🎁⬇️ | 🟢 绿 |
| 🎁 物 | ⬆️ 损失 | 削弱能力/资源减少 | 🎁⬆️ | 🔴 红 |

### 颜色编码

- 🟢 绿色 = 积极变化（出场/好事/获得）
- 🔴 红色 = 消极变化（退场/坏事/损失）

这有助于作者**一眼看出伏笔的情感走向**。

}

def interpret_foreshadow(carrier):
    return INTERPRETATION.get((carrier['primary'], carrier['secondary']), '未知')
