## 🎯 决策摘要

新增 **"聊天启发式填卡"** 功能：作者与 AI 引导式对话，按系统预设问题逐项填入档案。

**核心价值**：
- ✅ **思维发散**（不脱离主线）
- ✅ **降低填卡门槛**（不需要作者自己知道所有字段）
- ✅ **结构化**（AI 引导 → 预设问题 → 自动填入）
- ✅ **可追溯**（每条答案都有上下文）

---

## 💬 用户洞察

> "**一个重大的系统功能。就是聊天启发式填卡。**
> 当前我们已经有了人物档案，那么能不能让 llm，通过这些表格选项，让后和作者聊天，问的问题都是我们系统设定好的呢？然后聊了什么就填写什么。**这样思维可能会发散很多，但又不脱离主线？**"

**核心设计哲学**：
- **不是自动生成**（避免幻觉）
- **是引导式对话**（让作者思考）
- **问的问题都是预设**（保证主线不偏）
- **聊了什么就填什么**（降低填表负担）

## ✅ 最终设计

### 1. 整体架构

```
┌─────────────────────────────────────────────────────┐
│  聊天启发式填卡（chat-fill.html）                    │
├─────────────────────────────────────────────────────┤
│                                                      │
│  1. 选择档案（13 个 section 之一）                    │
│     ↓                                                │
│  2. AI 引导式对话（3-8 轮）                         │
│     - 每一轮 = 1 个预设问题                           │
│     - 作者回答 → AI 追问（基于上轮答案）             │
│     - 实时填入对应字段                                │
│     ↓                                                │
│  3. 完成后自动跳转到档案页（已填好）                 │
│                                                      │
└─────────────────────────────────────────────────────┘
```

### 2. 13 个 section 的预设问题库

**示例：声音指纹 section**

```
Q1（热身）: 主角的口头禅是什么？或者他经常用的一个感叹词？
Q2: 主角绝对不会说的词有哪些？这些词能体现他的身份/性格吗？
Q3: 主角说话时会有什么标志性动作？（如：摸下巴、敲桌子、抛硬币）
Q4: 主角说话偏长句还是短句？他会主动解释还是简短回答？
Q5: 主角在什么场合会突然"破防"？那时候他的语气会怎么变？
Q6（验证）: 给我一个能体现主角说话风格的典型例子（他的一句话）
```

**示例：核心伪装动机 section**

```
Q1: 主角平时伪装成什么样？（外在表现）
Q2: 为什么要伪装？伪装对主角有什么好处？
Q3: 哪些人会看穿主角的伪装？哪些人不会？
Q4: 主角的伪装是完美的，还是有漏洞？
Q5: 什么事件会让主角"撕下面具"？撕下后他会变成什么样？
```

### 3. 交互流程（4 步）

```
步骤 1: 选择 section
   ↓ 用户从下拉框选 "声音指纹"
   ↓
步骤 2: AI 抛出第一个问题
   ↓ "主角的口头禅是什么？"
   ↓
步骤 3: 作者自由回答
   ↓ "他喜欢说'账不是这么算的'，因为他是商人"
   ↓
步骤 4: AI 追问（基于上轮答案）
   ↓ "那他绝对不会说哪些词？这些词能体现他的性格吗？"
   ↓
...（循环 3-8 轮）
   ↓
步骤 5: AI 总结 + 写入档案
   ↓ "基于您的回答，我填入了以下字段..."
   ↓ 用户确认 → 写入 books/<name>/character-profile.html
```

### 5. 后端逻辑

```python
class ChatFillSession:
    def __init__(self, book, section):
        self.book = book
        self.section = section  # 13 个 section 之一
        self.questions = load_question_bank(section)  # 5-8 个预设问题
        self.answers = []
        self.filled_fields = {}
        self.current_q_index = 0
    
    def start(self):
        """开始对话：返回第一个问题"""
        return self.questions[0]
    
    def answer(self, user_answer):
        """作者回答 → AI 追问 + 提取字段"""
        # 1. 保存用户答案
        self.answers.append(user_answer)
        
        # 2. AI 分析答案 → 提取字段
        extracted = self.extract_fields(user_answer)
        self.filled_fields.update(extracted)
        
        # 3. 决定下一步
        if self.current_q_index < len(self.questions) - 1:
            self.current_q_index += 1
            return self.questions[self.current_q_index]  # 下一个预设问题
        else:
            return "done"  # 所有问题完成
    
    def extract_fields(self, answer):
        """用 LLM 提取结构化字段"""
```

### 7. 用户体验设计

| 特性 | 价值 |
|------|------|
| **AI 引导式问题** | 作者不需要想"我要填什么" |
| **3-8 轮对话** | 不会太长，有节奏感 |
| **AI 追问** | 让作者想得更深 |
| **实时字段显示** | 看到自己的回答已记录 |
| **可撤回** | 答错了可以重新回答 |
| **保存草稿** | 中途退出可继续 |
