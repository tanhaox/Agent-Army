## 🎯 v2.6 最终方案

### 核心创新

**问题根源**: 批处理脚本中多次使用 `cd` 命令切换目录，导致两个 Python 进程的工作目录相互影响

**解决方案**: 使用 `start /D` 参数为每个进程设置独立工作目录

### 关键代码

**文件**: `C:\Users\tanha\Desktop\启动 AutoGen Web.bat`

```batch
REM ============================================================
REM AutoGen Dual-Port Launcher v2.6 (Fixed - Independent Directories)
REM Start 5006 (Ollama) + 5007 (AutoGen) in background
REM Date: 2026-02-10
REM Fix: Use /D parameter to set independent working directories
REM ============================================================

@echo off
chcp 65001 >nul
setlocal enabledelayedexpansion

REM 设置项目根目录
set PROJECT_ROOT=C:\AI-Agent-Local

REM ============================================================
REM Step 1: Kill existing processes
REM ============================================================

echo [INFO] Cleaning existing port processes...

REM Kill 5006
for /f "tokens=5" %%a in ('netstat -ano ^| findstr ":5006" ^| findstr "LISTENING"') do (
    taskkill /F /PID %%a >nul 2>&1
)

REM Kill 5007
for /f "tokens=5" %%b in ('netstat -ano ^| findstr ":5007" ^| findstr "LISTENING"') do (
    taskkill /F /PID %%b >nul 2>&1
)

REM Kill pythonw processes
taskkill /F /IM pythonw.exe >nul 2>&1

timeout /t 2 >nul

REM ============================================================
REM Step 2: Start 5006 (Ollama AI) - Independent Directory
REM ============================================================

echo [START] Port 5006 Service (Ollama AI)
echo   URL: http://localhost:5006
echo   Features: Single agent chat, OCR, Task orchestration

REM Delete old log
if exist "%PROJECT_ROOT%\projects\skills\ollama_ai\logs\ollama_web.log" (
    del /F /Q "%PROJECT_ROOT%\projects\skills\ollama_ai\logs\ollama_web.log" >nul 2>&1
)

REM 关键：使用 /D 参数设置独立工作目录
start /D "%PROJECT_ROOT%\projects\skills\ollama_ai" "" pythonw -u ollama_web.py

timeout /t 4 >nul

REM Verify 5006
netstat -ano | findstr ":5006" | findstr "LISTENING" >nul 2>&1
if errorlevel 1 (
    echo [ERROR] 5006 service failed to start!
) else (
    echo [OK] 5006 running in background
)

REM ============================================================
REM Step 3: Start 5007 (AutoGen) - Independent Directory
REM ============================================================

echo [START] Port 5007 Service (AutoGen Multi-Agent)
echo   URL: http://localhost:5007
echo   Features: Multi-agent collaboration, Agent management

REM Delete old log
if exist "%PROJECT_ROOT%\projects\skills\autogen-skill\logs\autogen_web.log" (
    del /F /Q "%PROJECT_ROOT%\projects\skills\autogen-skill\logs\autogen_web.log" >nul 2>&1
)

REM 关键：使用 /D 参数设置独立工作目录
start /D "%PROJECT_ROOT%\projects\skills\autogen-skill\web" "" pythonw -u app.py

timeout /t 4 >nul

REM Verify 5007
netstat -ano | findstr ":5007" | findstr "LISTENING" >nul 2>&1
if errorlevel 1 (
    echo [ERROR] 5007 service failed to start!
) else (
    echo [OK] 5007 running in background
)

REM ============================================================
REM Step 4: Show results and open browser
REM ============================================================

echo.
echo =========================================================
echo   Startup Results
echo =========================================================

REM Final verification
set ALL_OK=1

netstat -ano | findstr ":5006" | findstr "LISTENING" >nul 2>&1
if errorlevel 1 (
    echo   [XX] Port 5006 - NOT RUNNING
    set ALL_OK=0
) else (
    echo   [OK] Port 5006 - Ollama AI (Background)
)

netstat -ano | findstr ":5007" | findstr "LISTENING" >nul 2>&1
if errorlevel 1 (
    echo   [XX] Port 5007 - NOT RUNNING
    set ALL_OK=0
) else (
    echo   [OK] Port 5007 - AutoGen (Background)
)

echo.
if !ALL_OK! == 1 (
    echo [SUCCESS] Both services started in background!
    echo.
    echo   Access URLs:
    echo     - Ollama AI:     http://localhost:5006
    echo     - AutoGen:       http://localhost:5007
    echo.
    echo   Features:
    echo     - Click "Multi-Agent" button on 5006 page to jump to 5007
    echo     - Services running in background (no windows)
    echo     - Independent working directories (no conflicts)
    echo.
    timeout /t 2 >nul
    REM Open browser
    echo [OPEN] Opening browser...
    start http://localhost:5006
    timeout /t 1 >nul
)

echo [DONE] Services running in background
timeout /t 3 >nul
```

## 🔬 技术分析

### 1. 为什么 v2.3-v2.5 失败？

**问题**:
```batch
REM v2.3-v2.5 的错误做法
cd /d "%PROJECT_ROOT%\projects\kills\ollama_ai"
start /B pythonw -u ollama_web.py >logs\ollama_web.log 2>&1

cd /d "%PROJECT_ROOT%\projects\skills\autogen-skill\web"
start /B pythonw -u app.py >logs\autogen_web.log 2>&1
```

**失败原因**:
1. 批处理日志重定向 `>logs\ollama_web.log 2>&1` 与 Python 内部日志冲突
2. `cd` 命令在批处理中是全局的，可能影响其他进程
3. 多个进程共享同一控制台，工作目录可能被覆盖

### 2. v2.6 为什么成功？

**关键点**:
```batch
REM v2.6 的正确做法
start /D "%PROJECT_ROOT%\projects\skills\ollama_ai" "" pythonw -u ollama_web.py
start /D "%PROJECT_ROOT%\projects\skills\autogen-skill\web" "" pythonw -u app.py
```

**成功因素**:
1. ✅ `/D` 参数为每个进程设置独立工作目录
2. ✅ 移除批处理日志重定向，让 Python 自己管理日志
3. ✅ `""` 空标题防止创建新窗口
4. ✅ `pythonw.exe` 完全后台运行，无控制台窗口

### 3. Windows `start` 命令参数解析

```
start [/D directory] ["title"] [command]
```

| 参数 | 说明 | v2.6中的使用 |
|------|------|-------------|
| `/D` | 设置进程的起始目录 | `/D "path"` 独立工作目录 |
| `""` | 窗口标题（空字符串=无窗口） | `""` 防止窗口创建 |
| `pythonw` | Python无窗口版本 | 完全后台运行 |
| `-u` | 禁用Python输出缓冲 | 实时日志输出 |

## 💡 经验教训

### 1. Windows 批处理进程隔离

**教训**: 在批处理中启动多个后台服务时，必须确保每个进程有独立的工作目录

**错误做法**:
```batch
cd /d path1
start pythonw script1.py

cd /d path2
start pythonw script2.py
```

**正确做法**:
```batch
start /D path1 "" pythonw script1.py
start /D path2 "" pythonw script2.py
```

### 2. 日志文件权限冲突

**教训**: 不要在批处理中重定向日志到 Python 自己管理的日志文件

**错误做法**:
```batch
start pythonw app.py >logs\app.log 2>&1
```
→ 与 Python 内部 `logging.FileHandler('logs/app.log')` 冲突

**正确做法**:
```batch
start pythonw app.py
```
→ 让 Python 自己管理日志文件

### 3. 用户洞察的价值

**用户观察**:
> "之前是两个批处理文件，分别开启5006,5007端口，有没有可能合并成1个批处理后，某些服务，本来应该是2个进程的，让你合并成只有一个进程了？"

**价值**: 用户正确识别了问题根源 - 进程隔离问题

**启示**: 合并批处理文件时，必须保持服务的独立性
