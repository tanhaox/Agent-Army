## 📖 快速开始

### 方法 1：交互式创建（推荐）

```bash
# Windows
cd shared\scripts
create_project.bat

# Linux/Mac
cd shared/scripts
python create_project.py
```

然后按照提示选择：
1. 项目类型（skill/app/tool）
2. 项目名称（如 my-skill）
3. 项目描述
4. 作者名称

### 方法 2：命令行创建

```bash
# 创建技能项目
python create_project.py --type skill --name weather-skill --description "天气查询技能"

# 创建应用项目
python create_project.py --type app --name note-app --description "笔记应用"

# 创建工具项目
python create_project.py --type tool --name file-converter --description "文件转换工具"
```

### 方法 3：列出现有项目

```bash
python create_project.py --list
```

## 🎯 项目类型说明

### 1. Skill（技能）- 可复用功能模块

**特点**：
- ✅ 功能单一，职责明确
- ✅ 可被其他项目引用
- ✅ 有清晰的 API 接口
- ✅ 可独立运行和测试

**适用场景**：
- API 调用封装
- 数据处理模块
- 算法实现
- 业务逻辑组件

**生成结构**：
```
weather-skill/
├── weather_skill.py      # 主要技能代码
├── __init__.py           # 包初始化
├── requirements.txt      # 依赖
├── start_weather-skill.py # 启动脚本
├── start_weather-skill.bat
├── tests/                # 测试
├── examples/             # 示例
├── docs/                 # 文档
├── logs/                 # 日志
└── README.md             # 说明
```

### 2. App（应用）- 完整业务应用

**特点**：
- ✅ 有完整的用户界面（Web/CLI）
- ✅ 包含多个功能模块
- ✅ 有独立的配置和数据
- ✅ 可独立部署运行

**适用场景**：
- Web 应用
- CLI 工具集
- 完整的服务
- 复杂系统

**生成结构**：
```
note-app/
├── main.py               # 主程序
├── requirements.txt      # 依赖
├── start_note-app.py     # 启动脚本
├── start_note-app.bat
├── backend/             # 后端代码
├── data/                # 数据
├── tests/               # 测试
├── docs/                # 文档
├── logs/                # 日志
└── README.md            # 说明
```

### 3. Tool（工具）- 独立小工具

**特点**：
- ✅ 功能单一明确
- ✅ 命令行界面
- ✅ 轻量级，依赖少
- ✅ 可独立运行

**适用场景**：
- 文件处理工具
- 数据转换工具
- 命令行脚本
- 系统管理工具

**生成结构**：
```
file-converter/
├── main.py               # 主程序
├── requirements.txt      # 依赖
├── start_file-converter.py
├── start_file-converter.bat
├── utils/               # 工具函数
├── tests/               # 测试
├── logs/                # 日志
└── README.md            # 说明
```

## 🚀 创建后的步骤

### 1. 查看生成的项目

```bash
cd projects/skills/your-skill  # 或 apps/tools
ls -la
```

### 2. 编辑主要代码

```bash

```

### 3. 安装依赖（如有）

```bash
pip install -r requirements.txt
```

### 4. 运行测试

```bash
# 运行所有测试
python -m pytest tests/

# 或直接运行主程序
python start_your-skill.py
```

### 5. 更新 README

根据实际功能更新 `README.md`。

## 📝 项目命名规范

### ✅ 推荐的命名

| 类型 | 示例 | 说明 |
|------|------|------|
| **skill** | weather-skill | 小写+连字符 |
| **skill** | api-manager | 功能描述 |
| **app** | note-app | 应用类型 |
| **app** | task-manager | 业务功能 |
| **tool** | json-converter | 工具功能 |
| **tool** | log-analyzer | 分析工具 |

### ❌ 不推荐的命名

| 错误示例 | 问题 |
|---------|------|
| `MySkill` | 大写开头 |
| `my_skill` | 使用下划线（应用内部） |
| `my-skill-` | 结尾连字符 |
| `123-skill` | 数字开头 |
| `我的技能` | 中文名称 |

## 🎯 最佳实践

### 1. 命名建议

- 使用英文小写
- 使用连字符分隔单词
- 名称要能描述功能
- 避免过长的名称

### 2. 描述建议

- 简洁明了，一句话说明功能
- 使用中文描述（更友好）
- 突出核心价值

### 3. 开发流程

```bash
# 1. 创建项目
python create_project.py --type skill --name my-skill

# 2. 编辑代码
cd projects/skills/my-skill
vim my_skill.py

# 3. 编写测试
vim tests/test_my_skill.py

# 4. 运行测试
python -m pytest tests/

# 5. 运行项目
python start_my-skill.py

# 6. 更新 README
vim README.md
```

### 4. 测试驱动开发

```bash
# 先写测试
vim tests/test_my_skill.py

# 运行测试（失败）
python -m pytest tests/

# 编写代码
vim my_skill.py

# 运行测试（通过）
python -m pytest tests/

# 重构优化
vim my_skill.py
```

## 🐛 常见问题

### Q1: 创建项目时提示"项目目录已存在"

**A**: 目录已存在，请：
- 使用不同的名称
- 或删除现有目录

### Q2: 生成的代码有语法错误

**A**: 可能是 Python 版本问题，请确保使用 Python 3.7+。

### Q3: 如何修改模板？

**A**: 编辑 `create_project.py` 文件中的：
- `_create_skill_code()` - 技能模板
- `_create_app_code()` - 应用模板
- `_create_tool_code()` - 工具模板

### Q4: 生成的项目在哪里？

**A**:
- Skill: `projects/skills/项目名/`
- App: `projects/apps/项目名/`
- Tool: `projects/tools/项目名/`
