## 📋 关键词触发检查

### 场景 1: 服务相关操作

**触发关键词**:
- `启动服务` / `停止服务` / `重启服务`
- `测试服务` / `验证服务`
- `autogen` / `ollama` / `ocr` / `api_manager`
- `端口 5007` / `端口 5006`

**[立即检查]**:
```python
# 第一反应：使用服务管理技能
from service_manager_skill import create_manager
manager = create_manager()

# 启动
manager.start_service('服务名')

# 停止
manager.stop_service('服务名')

# 重启
manager.restart_service('服务名')

# 完整测试（清除缓存 → 启动 → 验证 → 停止）
manager.test_service('服务名', clear_cache=True, auto_stop=True)

# 获取状态
manager.get_service_status('服务名')
```

**禁止操作** ⚠️ **【严重警告】**:
- ❌ 手动 `python app.py`
- ❌ 手动查看日志文件
- ❌ 创建测试脚本
- ❌ **用 Bash 命令管理服务（netstat, taskkill, ps 等）**

**⚠️ 为什么禁止 Bash 命令？**

| Bash 命令 | 问题 | 用户体验 |
|----------|------|---------|
| `netstat -ano \| grep ":5007"` | ❌ 每次都弹窗确认 | 😤 烦死 |
| `taskkill /F /PID xxxxx` | ❌ 每次都弹窗确认 | 😤 烦死 |
| `cd path && python app.py` | ❌ 每次都弹窗确认 | 😤 烦死 |
| **服务管理技能** | ✅ 自动执行，无弹窗 | 😊 真方便 |

**对比**:
```python
# ❌ 错误方式（无数次弹窗）
# 每次命令都需要用户确认，用户会非常烦

# ✅ 正确方式（服务管理技能）
from service_manager_skill import create_manager
manager = create_manager()
result = manager.restart_service('autogen', wait=8)
# 一次操作，无弹窗，自动完成
```

**核心教训**:
> 🔥 服务管理就用服务管理技能，别用 Bash 命令折腾用户！
> 🔥 每次弹窗都是对用户的打扰，完全自动化才是目标！

## 🔄 执行流程（标准）

### 任何任务开始前

```
1. 识别任务类型
   ↓
2. 检查关键词触发
   ↓
3. 查找对应技能/工具
   ↓
4. 使用技能/工具（不绕路）
   ↓
5. 完成任务
```

### 示例：用户说"重启 AutoGen 服务"

**错误流程**（我刚才的做法）:
```
1. 听到"重启"
   ↓
2. 直接想：用 Bash 命令
   ↓
3. cd ... && python -c "..."
   ↓
4. 绕了一大圈
```

**正确流程**:
```
1. 听到"重启服务"
   ↓
2. 触发关键词：服务操作
   ↓
3. 检查清单：使用 service_manager_skill
   ↓
4. manager.restart_service('autogen')
   ↓
5. 完成（2分钟）
```
