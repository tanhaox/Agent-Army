## 🤖 AI 辅助开发最佳实践

### 1. 使用 AI 开发的原则

#### ✅ 推荐的做法

1. **明确需求**：向 AI 清晰描述需求和约束
2. **分步实现**：将复杂任务拆分成小步骤
3. **代码审查**：AI 生成代码后进行审查和测试
4. **理解代码**：确保理解 AI 生成的每一行代码
5. **版本控制**：每次重大改动后提交代码

#### ❌ 避免的做法

1. ❌ 盲目复制粘贴代码
2. ❌ 不理解就直接使用
3. ❌ 跳过测试步骤
4. ❌ 不进行代码审查
5. ❌ 一次性生成大量代码

### 2. AI 辅助开发流程

#### 阶段 1：需求讨论

```

3. 是否需要缓存？
4. 错误处理策略？

你: 1. 使用 OpenWeatherMap API
   2. 温度、湿度、天气状况
   3. 需要缓存，1小时过期
   4. 网络错误时返回缓存数据
```

## 🧪 测试标准和最佳实践

### 1. 测试类型

#### 单元测试

```python
# tests/test_user_service.py
import unittest
from user_service import UserService
from models import User

class TestUserService(unittest.TestCase):
    """用户服务单元测试"""

    def setUp(self):
        """测试前准备"""
        self.service = UserService(mock_db, mock_logger)

    def tearDown(self):
        """测试后清理"""
        pass

    def test_create_user_success(self):
        """测试成功创建用户"""
        # Arrange
        username = "alice"
        email = "alice@example.com"

        # Act
        result = self.service.create_user(username, email)

        # Assert
        self.assertTrue(result.is_success())
        self.assertEqual(result.data.username, username)

    def test_create_user_duplicate(self):
        """测试创建重复用户"""
        # Arrange
        username = "alice"
        self.service.create_user(username, "alice@example.com")

        # Act & Assert
        with self.assertRaises(DuplicateUserError):
            self.service.create_user(username, "bob@example.com")
```

#### 集成测试

```python
# tests/integration/test_api_integration.py
import unittest
from api import create_app

class TestAPIIntegration(unittest.TestCase):
    """API 集成测试"""

    def setUp(self):
        """测试前准备"""
        self.app = create_app(testing=True)
        self.client = self.app.test_client()

    def test_get_user_api(self):
        """测试获取用户 API"""
        response = self.client.get('/api/users/123')

        self.assertEqual(response.status_code, 200)
        data = response.get_json()
        self.assertEqual(data['id'], 123)
```

## 🐛 常见问题和解决方案

### 1. 导入错误

#### 问题：ModuleNotFoundError

```python
# ❌ 错误
from skill import MySkill

# ✅ 正确
from projects.skills.my_skill.my_skill import MySkill

# 或使用 sys.path
import sys
sys.path.insert(0, str(Path(__file__).parent.parent))
from my_skill import MySkill
```

#### 问题：相对导入错误

```python
# ❌ 错误（在 scripts/ 中）
from ..skill import MySkill

# ✅ 正确
import sys
from pathlib import Path
sys.path.insert(0, str(Path(__file__).parent.parent.parent))
from skills.my_skill.my_skill import MySkill
```

### 2. 路径问题

#### 问题：找不到文件

```python
# ❌ 错误（硬编码路径）
file_path = "C:\\Users\\username\\data.json"

# ✅ 正确（使用相对路径）
from pathlib import Path
file_path = Path(__file__).parent / "data" / "data.json"

# 或使用项目根目录
project_root = Path(__file__).parent.parent.parent
file_path = project_root / "data" / "data.json"
```

### 3. 配置问题

#### 问题：环境变量未设置

```python
# ❌ 错误（直接使用）
api_key = os.getenv("API_KEY")

# ✅ 正确（提供默认值和错误提示）
api_key = os.getenv("API_KEY")
if not api_key:
    raise ValueError(
        "API_KEY 环境变量未设置。"
        "请在 .env 文件中设置 API_KEY=your_key_here"
    )
```

### 4. 日志问题

#### 问题：日志不输出

```python
# ❌ 错误（未配置日志）
import logging
logging.info("test")  # 不会输出

# ✅ 正确（配置日志）
import logging
from pathlib import Path

log_dir = Path(__file__).parent / "logs"
log_dir.mkdir(exist_ok=True)

logging.basicConfig(
    level=logging.INFO,
    format='%(asctime)s [%(levelname)s] %(name)s: %(message)s',
    handlers=[
        logging.FileHandler(log_dir / "app.log", encoding='utf-8'),
        logging.StreamHandler()
    ]
)

logger = logging.getLogger(__name__)
logger.info("test")  # 会输出到文件和控制台
```

### 5. 性能问题

#### 问题：循环中重复创建对象

```python
# ❌ 错误（每次循环都创建）
for item in items:
    client = ApiClient()  # 重复创建
    result = client.process(item)

# ✅ 正确（复用对象）
client = ApiClient()
for item in items:
    result = client.process(item)
```
