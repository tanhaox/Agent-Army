## 概述

AI-Agent-Local 测试框架提供标准化的测试基础设施，包括：

- ✅ **测试基类** - 通用测试基类和断言方法
- ✅ **pytest 配置** - 完整的 pytest 配置和 fixtures
- ✅ **测试工具** - 丰富的测试辅助函数
- ✅ **测试夹具** - 可复用的测试夹具
- ✅ **测试模板** - 单元、集成、性能测试模板
- ✅ **覆盖率报告** - 自动化覆盖率报告

## 快速开始

### 1. 安装依赖

```bash
pip install -r requirements-dev.txt
```

主要依赖：
- `pytest` - 测试框架
- `pytest-cov` - 覆盖率报告
- `pytest-html` - HTML 报告
- `pytest-xdist` - 并行测试

### 2. 运行测试

```bash
# 运行所有测试
pytest

# 运行特定项目的测试
pytest projects/skills/api_manager/tests/

# 运行单个测试文件
pytest projects/skills/api_manager/tests/test_api.py

# 运行特定测试
pytest projects/skills/api_manager/tests/test_api.py::TestAPI::test_get
```

### 3. 查看覆盖率

```bash
# 生成覆盖率报告
pytest --cov=. --cov-report=html

# 查看报告
start htmlcov/index.html  # Windows
open htmlcov/index.html   # macOS
```

### 4. 使用测试脚本

```bash
# Windows
run_tests.bat

# Linux/Mac
chmod +x run_tests.sh
./run_tests.sh
```

## 测试基类

### BaseTestCase

所有测试的基类，提供通用功能。

```python
from shared.testing.test_base import BaseTestCase

class MyTest(BaseTestCase):
    def test_example(self):
        # 使用临时目录
        temp_file = self.temp_path / "test.txt"
        temp_file.write_text("内容")

        # 使用日志
        self.logger.info("测试消息")

        # 使用测试数据
        data = self.load_json_data("test_data.json")
```

### BaseSkillTestCase

技能测试基类，提供技能特定的测试方法。

```python
from shared.testing.test_base import BaseSkillTestCase

class TestMySkill(BaseSkillTestCase):
    def setUp(self):
        super().setUp()
        self.skill = MySkill()

    def test_skill_execute_success(self):
        # 断言技能执行成功
        self.assertSkillExecuteSuccess(param="value")

    def test_skill_execute_failed(self):
        # 断言技能执行失败
        self.assertSkillExecuteFailed(invalid_param="invalid")
```

### BaseAppTestCase / BaseToolTestCase

应用和工具测试基类。

```python
from shared.testing.test_base import BaseAppTestCase, BaseToolTestCase

class TestMyApp(BaseAppTestCase):
    def test_app_can_start(self):
        self.assertAppCanStart()

class TestMyTool(BaseToolTestCase):
    def test_tool_has_cli(self):
        self.assertToolHasCLI()
```

## pytest 配置

### 使用 Fixtures

```python
def test_temp_file(temp_file):
    """使用临时文件 fixture"""
    file = temp_file("test.txt", "内容")
    assert file.exists()

def test_temp_dir(temp_dir):
    """使用临时目录 fixture"""
    test_file = temp_dir / "test.txt"
    test_file.write_text("内容")
    assert test_file.exists()

def test_sample_project(sample_project):
    """使用示例项目 fixture"""
    assert (sample_project / "README.md").exists()

def test_log_fixture(test_log):
    """使用日志 fixture"""
    logger, log_file = test_log
    logger.info("测试消息")
    assert log_file.exists()
```

### 使用标记

```bash
# 只运行单元测试
pytest -m unit

# 只运行集成测试
pytest -m integration

# 跳过慢速测试
pytest -m "not slow"
```

### 参数化测试

```python
@pytest.mark.parametrize("input,expected", [
    (1, 2),
    (2, 4),
    (3, 6),
])
def test_multiply_by_two(input, expected):
    assert input * 2 == expected
```

## 测试工具函数

### JSON 验证

```python
from shared.testing.utils import assert_valid_json, assert_json_schema

# 验证有效的 JSON
assert_valid_json({"key": "value"})

# 验证 JSON schema
data = {"name": "John", "age": 30}
schema = {"name": str, "age": int}
assert_json_schema(data, schema)
```

### 日志验证

```python

# 验证日志包含模式
assert_log_contains(log_file, r"\[INFO\].*成功")

# 验证日志级别
assert_log_level_exists(log_file, "ERROR")

# 统计日志条目
count = count_log_entries(log_file, level="INFO")
```

### 文件系统

```python
from shared.testing.utils import assert_file_exists, create_temp_file

# 验证文件存在
assert_file_exists(test_file)

# 创建临时文件
temp_file = create_temp_file(content="测试内容")
```

### 配置模拟

```python
from shared.testing.utils import mock_config

with mock_config({"api_key": "test"}):
    # 测试代码
    pass
```

### 性能测试

```python

# 测量执行时间
result, time_taken = measure_execution_time(my_function)

# 断言执行时间
assert_execution_time(my_function, max_time=1.0)
```

## 覆盖率报告

### 生成报告

```bash
# 终端报告（显示未覆盖的行）
pytest --cov=. --cov-report=term-missing

# HTML 报告
pytest --cov=. --cov-report=html

# XML 报告（用于 CI）
pytest --cov=. --cov-report=xml
```

### 配置覆盖率

在 `.coveragerc` 中配置：

```ini
[coverage:run]
source = .
omit = */tests/*, */__pycache__/*

[coverage:report]
precision = 2
show_missing = True
```

### 查看报告

```bash
# 打开 HTML 报告
start htmlcov/index.html  # Windows
open htmlcov/index.html   # macOS
xdg-open htmlcov/index.html  # Linux
```

## 最佳实践

### 1. 测试命名

```python
# 好的命名
def test_skill_returns_success_on_valid_input():
    pass

def test_skill_raises_error_with_invalid_param():
    pass

# 避免的命名
def test1():
    pass
```

### 2. 测试结构

使用 AAA 模式（Arrange-Act-Assert）：

```python
def test_skill_processes_data():
    # Arrange - 准备测试数据
    input_data = {"key": "value"}

    # Act - 执行被测试的操作
    result = skill.process(input_data)

    # Assert - 验证结果
    assert result["status"] == "success"
```

### 3. 使用描述性的断言

```python
# 好的断言
self.assertEqual(result.status, "success", "技能应该返回成功状态")

# 避免的断言
self.assertEqual(result.status, "success")
```

### 4. 测试边界条件

```python
def test_with_empty_input():
    result = skill.process("")
    assert result.status == "error"

def test_with_none_input():
    result = skill.process(None)
    assert result.status == "error"

def test_with_large_input():
    large_data = "x" * 1000000
    result = skill.process(large_data)
    assert result.status == "success"
```

### 5. 保持测试独立

```python
# 好的示例 - 每个测试独立
def test_create_item():
    item = create_item(name="test")
    assert item.id is not None

def test_update_item():
    item = create_item(name="test")
    updated = update_item(item.id, name="updated")
    assert updated.name == "updated"

# 避免的示例 - 测试依赖顺序
def test_create_item():
    global item
    item = create_item(name="test")

def test_update_item():
    updated = update_item(item.id, name="updated")
```

### 6. 使用 Mock 隔离依赖

```python
from unittest.mock import patch

def test_skill_with_external_api():
    with patch('requests.get') as mock_get:
        mock_get.return_value.json.return_value = {"data": "test"}

        result = skill.fetch_data()

        mock_get.assert_called_once()
        assert result == {"data": "test"}
```
