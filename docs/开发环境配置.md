## 🔧 开发规范

### 编码规范

#### 1. 避免 Emoji 字符

**原因**:
- Windows 命令行编码问题（GBK vs UTF-8）
- 脚本输出可能出现乱码
- 跨平台兼容性问题

**规定**:
- ❌ **禁止**在代码中使用 emoji 字符
- ❌ **禁止**在脚本输出中使用 emoji
- ✅ **允许**在文档中使用 emoji（Markdown 文件）
- ✅ 使用文本替代：`[OK]`、`[XX]`、`[INFO]`、`[WARN]`

**示例**:

```python
# 错误示例
print("✅ 操作成功")
print("❌ 操作失败")

# 正确示例
print("[OK] 操作成功")
print("[XX] 操作失败")
```

```python
# 状态标识
STATUS_OK = "[OK]"
STATUS_ERROR = "[XX]"
STATUS_INFO = "[INFO]"
STATUS_WARN = "[WARN]"
```

#### 2. 编码声明

**Python 文件头部**:
```python
#!/usr/bin/env python
# -*- coding: utf-8 -*-
"""
文件描述
"""
```

**批处理文件**:
```batch
@echo off
chcp 65001 > nul
REM 中文注释
```

#### 3. 输出格式

**使用纯 ASCII 或兼容 UTF-8 的文本**:
```python
# 推荐
print("="*70)
print("服务管理技能")
print("="*70)

# 避免
print("🚀 服务管理技能")
```

## 🐛 常见问题

### 1. 中文乱码

**问题**: Windows 命令行输出中文乱码

**解决方案**:
```python
import sys
import io

# 设置输出编码
sys.stdout = io.TextIOWrapper(sys.stdout.buffer, encoding='utf-8')
```

或在批处理文件中：
```batch
chcp 65001 > nul
```

### 2. emoji 显示异常

**问题**: emoji 字符显示为方块或乱码

**解决方案**: 使用文本替代
```python
# 不要用
print("✅ 成功")

# 改用
print("[OK] 成功")
```

### 3. 路径问题

**问题**: Git Bash 路径解析错误

**解决方案**:
- 使用正斜杠: `C:/AI-Agent-Local`
- 使用引号: `"c:/AI-Agent-Local/shared/scripts/save_memory.py"`
- 避免使用 `start /B` 等混合命令

## 🔍 环境检测脚本

创建一个脚本来自动检测环境：

```python
# check_environment.py
import platform
import sys
import psutil

def check_environment():
    """检测开发环境"""
    print("="*70)
    print("环境检测")
    print("="*70)

    # Python
    print(f"\nPython: {platform.python_version()}")

    # 系统
    print(f"系统: {platform.system()} {platform.release()}")
    print(f"架构: {platform.machine()}")

    # 内存
    mem = psutil.virtual_memory()
    print(f"内存: {mem.total // (1024**3)} GB")

    # CPU
    print(f"CPU 核心: {psutil.cpu_count(logical=False)} 物理 / {psutil.cpu_count(logical=True)} 逻辑")

    # 关键包
    packages = ['flask', 'httpx', 'requests', 'ollama']
    for pkg in packages:
        try:
            mod = __import__(pkg)
            version = getattr(mod, '__version__', 'unknown')
            print(f"{pkg}: {version}")
        except ImportError:
            print(f"{pkg}: 未安装")

if __name__ == "__main__":
    check_environment()
```
