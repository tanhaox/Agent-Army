### 4. 航班数据调度服务启动 ✅ (P0) **关键**

**修改位置**: `:production` 标签，构建之后，Web 服务器启动之前

**新增代码**:
```bat
echo [5/7] Starting Flight Scheduler Service...
echo ===============================================
echo   FLIGHT SCHEDULER WINDOW WILL OPEN
echo   LOOK FOR: Flight-Scheduler WINDOW
echo   This service runs 24/7 to update flight data
echo   Strategy 1: 22:00-23:59 every 10min (tomorrow data)
echo   Strategy 2: Every hour (today updates)
echo ===============================================
echo.
cd /d "%PROJECT_ROOT%"
start "Flight-Scheduler" cmd /k "echo Flight Data Scheduler Service && echo. && echo Strategy 1: Tomorrow data (22:00-23:59, every 10min) && echo Strategy 2: Today updates (00:00-23:59, every hour) && echo. && cd /d %CD% && npx tsx src/lib/airport/scheduler-service.ts"
timeout /t 3 /nobreak >nul
echo [OK] Flight scheduler started
echo.
```

**功能**:
- 在独立窗口启动调度服务
- 显示调度策略说明
- 窗口标题: "Flight-Scheduler"
- 服务持续运行 24/7

**调度策略**:
- **策略 1**: 每天 22:00-23:59，每 10 分钟抓取明天航班数据
- **策略 2**: 全天 00:00-23:59，每小时更新今天航班数据

**影响**: **这是航班预测功能的核心，没有它航班数据不会更新**

## ⚠️ 重要提示

### PKX 数据源警告

PKX（大兴机场）当前使用临时爬取方案，生产环境必须替换！

**临时方案风险**:
- 网站结构变化会导致爬取失败
- 单次抓取耗时 ~30 秒
- 需要占用 ~1GB 内存（Chrome 浏览器）
- 可能违反网站服务条款

**推荐替换方案**:
1. **最佳**: 联系大兴机场获取官方 API
2. **推荐**: 联系 Trip.com 获取 API 接口
3. **可行**: 使用第三方数据服务

**降级策略**:
- PKX 爬取失败时返回空数组
- 不影响 PEK（首都机场）数据
- 系统继续正常运行

相关文档: [⚠️-PKX-临时方案警告.md](C:\AI-Agent-Local\miaoying\⚠️-PKX-临时方案警告.md)

## 📝 使用说明

### 启动生产环境

1. 双击 `Start-Miaoying-Production.bat`
2. 选择 `1. Start Production Mode`
3. 等待所有检查和启动完成
4. 两个窗口会打开:
   - **Miaoying-Server**: Web 服务器
   - **Flight-Scheduler**: 航班数据调度服务

### 查看系统状态

1. 在主菜单选择 `5. View System Status`
2. 查看所有服务运行状态
3. 特别关注 "Flight Scheduler" 状态

### 停止系统

1. 在主菜单选择 `6. Cleanup and Stop`
2. 确认清理操作
3. 所有服务会按顺序停止
