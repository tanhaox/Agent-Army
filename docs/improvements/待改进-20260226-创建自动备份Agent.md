**创建日期**: 2026-02-26
**状态**: 待改进

## 一、需求描述

### 背景
当前 AI-Agent-Local 项目缺乏自动备份机制，代码修改存在风险：
- 代码意外丢失
- 错误修改无法回滚
- 大型错误难以恢复

### 目标
创建一个全局自动备份 Agent，实现：
1. **实时监控**对话内容，检测到代码修改相关关键词时立即备份
2. **整点定时备份**（每小时）
3. **简单回滚**机制，支持按时间/关键词/ID 回滚
4. **全程自动化**，无需用户干预

### 核心价值
- 🛡️ 防止代码丢失
- 🔄 随时回滚到任意备份点
- 🤖 全自动运行，用户无感知
- 📝 完整的修改历史记录

### 2.2 功能设计

#### 核心功能

**1. 对话内容监控**
- 实时监控 VSCode 中与 Claude 的对话
- 检测关键词：
  ```
  方案、bug、漏洞、升级、修复、添加功能、改进、
  开发、实现、重构、优化、部署、更新
  ```
- 检测到关键词 → 立即触发备份

**2. 整点定时备份**
- 每小时整点（00分）检查
- 执行 `git status` 检测文件修改
- 有修改 → 执行备份

**3. Git 备份机制**
- 首次运行时初始化 Git 仓库（如果未初始化）
- 自动执行：
  ```bash
  git add .
  git commit -m "💾 [关键词触发] 在检测到'XX'讨论前 - 2026-02-26 14:35"
  ```

**4. 回滚命令**
```bash
# 查看最近 12 小时内的备份清单
backup-agent --list

# 回滚到特定备份（按时间）
backup-agent --rollback "2026-02-26 14:35"

# 回滚到特定备份（按关键词）
backup-agent --rollback "bug讨论前"

# 回滚到特定备份（按ID）
backup-agent --rollback 1
```

**5. 用户通知**
- 备份开始：`老板，我在备份...`
- 备份完成：`老板，我备份好了`
- 完全自动化，不请求用户确认

### 2.5 实现细节

#### 对话监控实现

**方案**：读取 VSCode Claude Code 扩展的对话历史

**技术路径**：
1. 监控当前对话内容（通过上下文获取）
2. 实时检测关键词
3. 检测到关键词 → 触发备份

**挑战**：如何获取当前对话内容？
- **方案 A**：监控 Claude Code 的日志文件（如果有）
- **方案 B**：通过文件系统监控，检测 `.claude` 或相关目录
- **方案 C**：用户提供对话内容接口（需要协调）

**建议**：先实现基于文件系统监控的简化版本，监控 `docs/improvements/` 目录的变化（因为讨论后会创建改进意见文档）

**优化方案**：
- 监控 `docs/improvements/` 目录
- 检测到新文件创建（`待改进-*.md`）→ 触发备份
- 这样可以捕获"讨论 → 创建改进意见"的流程

#### 定时备份实现

```python
import schedule
import time

def hourly_backup():
    """整点备份"""
    if git_manager.has_changes():
        git_manager.backup("整点备份", "hourly")
        print("老板，我备份好了")

# 每小时的 00 分执行
schedule.every().hour.at(":00").do(hourly_backup)

while True:
    schedule.run_pending()
    time.sleep(1)
```

#### Git 操作封装

```python
class GitManager:
    def __init__(self, repo_path):
        self.repo = git.Repo(repo_path)

    def has_changes(self):
        """检查是否有未提交的修改"""
        return self.repo.is_dirty() or len(self.repo.untracked_files) > 0

    def backup(self, message, backup_type, keyword=None):
        """执行备份"""
        # git add .
        self.repo.index.add(["."])

        # 生成 commit 消息
        commit_msg = self._generate_commit_message(backup_type, keyword)

        # git commit
        self.repo.index.commit(commit_msg)

        return commit_msg

    def _generate_commit_message(self, backup_type, keyword=None):
        """生成 commit 消息"""
        now = datetime.now().strftime("%Y-%m-%d %H:%M")
        if backup_type == "keyword":
            return f"💾 [关键词触发] 在检测到'{keyword}'讨论前 - {now}"
        else:
            return f"💾 [整点备份] 定时备份 - {now}"
```

## 六、风险和注意事项

### 6.1 技术风险

**风险 1**：对话内容监控可能无法实现
- **原因**：VSCode Claude Code 扩展的对话内容可能无法直接访问
- **缓解方案**：改为监控 `docs/improvements/` 目录，检测新文件创建

**风险 2**：Git 初始化可能冲突
- **原因**：如果项目已经是 Git 仓库，不需要初始化
- **缓解方案**：先检测是否已存在 `.git` 目录

**风险 3**：关键词误触发
- **原因**：日常对话中可能提到关键词，但不涉及代码修改
- **缓解方案**：
  - 调整关键词列表
  - 增加冷却期（同一关键词 10 分钟内不重复触发）

### 6.2 使用风险

**风险 1**：频繁备份可能影响性能
- **缓解方案**：只在检测到文件修改时才备份

**风险 2**：回滚可能导致代码丢失
- **缓解方案**：回滚前自动创建一个备份点
