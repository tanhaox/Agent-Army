## 🔍 功能验证

### 验证 1: 航班数据抓取

**目的**: 确认调度服务实际抓取数据

**步骤**:
1. 启动生产模式（包括调度服务）
2. 等待调度服务执行（可能需要等到整点）
3. 检查数据库

**方法**:
```sql
-- 检查是否有新数据
SELECT
    airport_code,
    COUNT(*) as flight_count,
    MAX(fetched_at) as last_fetch
FROM arrival_flights
WHERE fetched_at > NOW() - INTERVAL '1 hour'
GROUP BY airport_code;
```

**预期结果**:
- ✅ PEK 有数据（~1500 条）
- ✅ PKX 有数据（如果 Python 已安装，~14 条）
- ✅ last_fetch 时间是最近的
