## 📋 当前问题分析

### ❌ 缺少的功能

当前批处理文件**只启动了 Next.js Web 服务器**,但缺少以下关键服务:

1. **航班数据调度服务** ⚠️ **关键**
   - 文件位置: `src/lib/airport/scheduler-service.ts`
   - 功能: 自动抓取 PEK/PKX 航班数据
   - 调度策略:
     - 策略1: 22:00-23:59 每10分钟抓取明天数据
     - 策略2: 00:00-23:59 每小时更新今天数据
   - **必须独立运行**,否则航班预测功能无数据

2. **Python 环境检查**
   - PKX 爬取需要 Python + undetected-chromedriver
   - 当前没有检查 Python 是否安装

3. **依赖项检查**
   - node-cron (Node.js 定时任务库)
   - 当前未检查是否安装

## ✅ 建议改进方案

### 改进 1: 添加调度服务启动

在 `:production` 和 `:development` 两个标签中,启动调度服务:

```bat
echo [6/7] Starting Flight Scheduler Service...
echo ===============================================
echo   SCHEDULER WINDOW WILL OPEN
echo   LOOK FOR: Flight-Scheduler WINDOW
echo   This service runs in background 24/7
echo ===============================================
echo.
cd /d "%PROJECT_ROOT%"
start "Flight-Scheduler" cmd /k "echo Flight Data Scheduler Service && echo. && echo Strategy 1: Tomorrow data (22:00-23:59, every 10min) && echo Strategy 2: Today updates (00:00-23:59, every hour) && echo. && cd /d %CD% && npx tsx src/lib/airport/scheduler-service.ts"
timeout /t 3 /nobreak >nul
echo [OK] Flight scheduler started
echo.
```

**位置**: 在启动 Web 服务器**之后**

### 改进 2: 添加 Python 环境检查

在 `:production` 的环境变量检查部分之后添加:

```bat
echo [1.5/6] Checking Python environment...
python --version >nul 2>&1
if errorlevel 1 (
    echo [WARN] Python not found! PKX flight scraping will fail
    echo [WARN] PKX scraping requires Python + undetected-chromedriver
    echo        PEK (Capital Airport) will work normally
    echo.
    set /p continue=Continue anyway? (y/N):
    if /i not "%continue%"=="y" goto menu
) else (
    echo [OK] Python found
    python --version
)
echo.
```

**位置**: 在环境变量检查之后,Docker 检查之前

### 改进 3: 添加 node-cron 依赖检查

在构建检查之前添加:

```bat
echo [3.5/6] Checking flight scheduler dependencies...
cd /d "%PROJECT_ROOT%"
if not exist "node_modules\node-cron" (
    echo [WARN] node-cron not found, installing...
    call pnpm add node-cron
    if errorlevel 1 (
        echo [ERROR] Failed to install node-cron
        pause
        goto menu
    )
)
echo [OK] Flight scheduler dependencies ready
echo.
```

**位置**: 在停止进程之后,构建之前

### 改进 4: 更新版本号

```bat
set VERSION=v2.6.0
```

**原因**: 包含航班预测系统的重大功能更新

### 改进 5: 更新菜单说明

在主菜单中添加提示:


### 改进 6: 添加调度服务状态检查

在 `:status` 标签中添加:

```bat
echo 7. Flight Scheduler:
tasklist | findstr /C:"scheduler-service" >nul
if errorlevel 1 (
    echo    [ERROR] Not running (Flight data will not update!)
) else (
    echo    [OK] Running (Flight data updates automatically)
)
echo.
```

### 改进 7: 清理时停止调度服务

在 `:cleanup` 标签中添加:

```bat
echo [1.5/4] Stopping Flight Scheduler...
taskkill /FI "WINDOWTITLE eq Flight-Scheduler*" >nul 2>&1
echo [OK] Flight scheduler stopped
echo.
```
