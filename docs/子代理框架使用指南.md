## 概述

### 什么是子代理框架？

子代理框架（Subagent Framework）是 AI-Agent-Local 的核心组件，实现了 **SADD（Subagent-Driven Development）** 模式。

**核心特点**：
- ✅ **Fresh subagent per task** - 每个任务使用独立的子代理，上下文隔离
- ✅ **Quality gates** - 任务间自动代码审查
- ✅ **Parallel execution** - 并行处理独立任务
- ✅ **Fast iteration** - 快速迭代优化

## 核心概念

### 1. Task（任务）

任务是工作的基本单位，包含：

```python
@dataclass
class Task:
    id: str                  # 唯一标识符
    name: str                # 任务名称
    description: str         # 任务描述
    requirements: str        # 详细要求
    directory: Optional[str] # 工作目录
    files: List[str]         # 相关文件
    dependencies: List[str]  # 依赖任务
    priority: int            # 优先级 (0-4)
    complexity: str          # 复杂度 (low/medium/high)
    task_type: str           # 任务类型
    status: TaskStatus       # 任务状态
```

**任务类型**：
- `development` - 开发任务（使用 Sonnet）
- `architecture` - 架构设计（使用 Opus）
- `testing` - 测试任务（使用 Haiku）
- `documentation` - 文档任务（使用 Haiku）
- `review` - 代码审查（使用 Opus）

### 2. TaskStatus（任务状态）

```
PENDING      → 等待执行
IN_PROGRESS  → 执行中
COMPLETED    → 已完成
FAILED       → 失败
REVIEWING    → 审查中
BLOCKED      → 被阻塞
```

### 3. ModelSelector（模型选择器）

根据任务类型和复杂度自动选择合适的模型：

| 任务类型 | 基础模型 | 高复杂度升级 |
|---------|---------|-------------|
| architecture | opus | opus |
| coding | sonnet | opus |
| testing | haiku | sonnet |
| documentation | haiku | sonnet |
| review | opus | opus |

### 4. ExecutionStrategy（执行策略）

**SequentialStrategy（顺序执行）**：
- 任务按顺序执行
- 每个任务后进行代码审查
- 发现关键问题自动修复
- 适合有依赖关系的任务

**ParallelStrategy（并行执行）**：
- 独立任务并行执行
- 最后批量审查
- 节省时间
- 适合无依赖关系的任务

## 快速开始

### 基础示例

```python
import asyncio
from shared.subagents.dispatcher import create_dispatcher, create_task

async def main():
    # 创建任务
    task = create_task(
        task_id="task-1",
        name="实现用户认证",
        description="JWT 认证功能",
        requirements="""
        1. 实现 /auth/login 端点
        2. 实现 /auth/register 端点
        3. 使用 JWT token 机制
        """,
        priority=1,
        complexity="high",
        task_type="development"
    )

    # 创建调度器
    dispatcher = create_dispatcher(mode="sequential")

    # 执行任务
    results = await dispatcher.execute([task], mode="sequential")

    # 查看结果
    for result in results:
        print(f"任务 {result.task_id}: {result.status.value}")
        print(f"输出: {result.output}")

asyncio.run(main())
```

### 自定义模型选择

```python
from shared.subagents.dispatcher import ModelSelector

# 自定义模型选择器
class CustomModelSelector(ModelSelector):
    @classmethod
    def select_model(cls, task_type, complexity, explicit_model=None):
        if explicit_model:
            return explicit_model

        # 所有任务都使用 opus
        return "opus"

# 使用自定义选择器
dispatcher = create_dispatcher(model_selector=CustomModelSelector())
```

## 高级用法

### 1. 带依赖关系的任务

```python
tasks = [
    create_task(
        task_id="task-1",
        name="实现认证功能",
        requirements="实现登录和注册",
        priority=1
    ),
    create_task(
        task_id="task-2",
        name="编写认证测试",
        requirements="测试登录和注册",
        priority=2,
        dependencies=["task-1"]  # 依赖 task-1
    ),
    create_task(
        task_id="task-3",
        name="编写认证文档",
        requirements="API 文档",
        priority=3,
        dependencies=["task-1"]  # 依赖 task-1
    ),
]

# 调度器会自动按依赖顺序执行
results = await dispatcher.execute(tasks, mode="sequential")
```

### 2. 并行执行独立任务

```python
tasks = [
    create_task(task_id="task-1", name="编写测试"),
    create_task(task_id="task-2", name="编写文档"),
    create_task(task_id="task-3", name="性能优化"),
]

# 并行执行（假设这三个任务相互独立）
results = await dispatcher.execute(tasks, mode="parallel")
```

### 3. 自定义代码审查规则

```python
from shared.subagents.reviewer import ReviewRule, CodeReviewIssue

class CustomRule(ReviewRule):
    def __init__(self):
        super().__init__(
            name="custom_check",
            category=IssueCategory.BUG,
            default_severity=Severity.IMPORTANT
        )

    def check(self, code, file_path=""):
        issues = []
        # 自定义检查逻辑
        if "TODO" in code:
            issues.append(CodeReviewIssue(
                severity=Severity.IMPORTANT,
                category=self.category.value,
                description="代码中包含 TODO 标记",
                location=file_path
            ))
        return issues

# 使用自定义规则
from shared.subagents.reviewer import create_reviewer

reviewer = create_reviewer(custom_rules=[CustomRule()])
dispatcher = Dispatcher(reviewer=reviewer)
```

### 4. 集成评估驱动开发工作流


## 最佳实践

### 1. 任务设计原则

**单一职责**：
- ✅ 一个任务只做一件事
- ❌ 不要在一个任务中混合开发和测试

**明确要求**：
- ✅ 提供清晰的 requirements
- ✅ 指定相关文件和目录
- ❌ 不要使用模糊的描述

**合理优先级**：
- 0 = critical（必须立即完成）
- 1 = high（优先完成）
- 2 = medium（正常优先级）
- 3 = low（有时间再做）
- 4 = backlog（暂缓）

### 2. 模型选择建议

| 场景 | 推荐模型 | 原因 |
|------|---------|------|
| 架构设计 | opus | 需要深度思考 |
| 核心开发 | sonnet | 性价比高 |
| 简单任务 | haiku | 快速执行 |
| 代码审查 | opus | 需要仔细分析 |
| 文档生成 | haiku | 生成速度快 |

### 3. 执行模式选择

**使用顺序执行当**：
- ✅ 任务有依赖关系
- ✅ 需要严格质量控制
- ✅ 需要实时反馈

**使用并行执行当**：
- ✅ 任务相互独立
- ✅ 追求执行速度
- ✅ 资源充足

### 4. 错误处理

```python
try:
    results = await dispatcher.execute(tasks, mode="sequential")

    # 检查失败的任务
    failed_tasks = [r for r in results if r.status == TaskStatus.FAILED]

    if failed_tasks:
        print(f"有 {len(failed_tasks)} 个任务失败")
        for result in failed_tasks:
            print(f"任务 {result.task_id}: {result.output}")

except Exception as e:
    print(f"执行失败: {e}")
```

## 常见问题

### Q: 如何查看任务执行进度？

A: 使用 `TrackedDispatcher`：

```python
from shared.subagents.progress_tracker import create_tracked_dispatcher

dispatcher = create_tracked_dispatcher(enable_progress_tracking=True)
results = await dispatcher.execute(tasks)
```

### Q: 如何调整质量标准？

A: 使用工作流并设置 `quality_threshold`：

```python
from shared.subagents.workflow import create_workflow

workflow = create_workflow(quality_threshold=8.0)  # 更高的标准
```

### Q: 如何禁用代码审查？

A: 创建调度器时设置 `enable_review=False`：

```python
dispatcher = TrackedDispatcher(enable_review=False)
```

### Q: 如何处理任务失败？

A: 检查结果状态并采取行动：

```python
results = await dispatcher.execute(tasks)

for result in results:
    if result.status == TaskStatus.FAILED:
        # 重试或记录错误
        print(f"任务 {result.task_id} 失败: {result.output}")
```
