## 🔧 故障排查

### 如果配置没有生效

1. **检查文件位置**
   ```bash
   # 必须在项目根目录
   C:\AI-Agent-Local\.claude\settings.local.json
   ```

2. **检查 JSON 格式**
   ```bash
   python -m json.tool .claude/settings.local.json
   ```
   应该显示格式化的 JSON，没有错误

3. **重启 Claude Code**
   - 完全关闭
   - 重新打开

4. **验证配置**
   在对话中询问：``你当前的自动化权限是什么？``
