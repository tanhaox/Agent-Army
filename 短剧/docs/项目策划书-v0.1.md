> **版本**: v0.1 (概要版)
> **日期**: 2026-04-16
> **状态**: 讨论中

---

## 1. 项目概述

### 1.1 一句话定位

**以 ComfyUI 为核心引擎、多平台视频 API 协同的 AI 短剧批量生产系统。**

### 1.2 解决的核心问题

个人创作者想要以工业化效率生产商业级短剧，但面临：
- 创意到成片的流程碎片化，需要在不同工具间反复切换
- 角色一致性难以保证，不同镜头角色"变脸"
- 多平台（抖音/快手/YouTube）格式要求不同，重复劳动
- 缺少批量生产能力，一部短剧耗时过长

### 1.3 目标用户

**自己**。一人公司，每月产出 3-5 部商业级竖屏微短剧。

### 1.4 成功标准

- 从创意到成片，单部短剧（10-20集）生产周期 ≤ 3天
- 角色跨镜头一致性 ≥ 95%
- 支持一键多平台发布（抖音/快手/YouTube/微信视频号）
- 月产量稳定 3-5 部

### 2.2 核心工作流

```
创意输入                    AI生成                     本地处理              发布
─────── → ─────────────── → ─────────────────── → ────────────── → ──────
           │                │                      │                 │
  小说/     │  剧本生成      │  分镜拆解             │  ComfyUI        │  抖音
  主题/     │  (Ollama/     │  角色参考图生成        │  角色一致性处理   │  快手
  关键词    │   云端API)     │  视频提示词生成        │  FFmpeg合成      │  YouTube
                            │                      │  配音/字幕       │  视频号
                            │  多平台视频生成        │                  │
                            │  (Kling/Seedance/)   │                  │
```

### 2.3 技术栈

| 层级 | 技术选型 | 理由 |
|------|---------|------|
| **前端** | Vue 3 + Pinia + Element Plus | 轻量、中文生态好 |
| **后端** | Python + FastAPI | 异步性能好，AI生态丰富 |
| **数据库** | PostgreSQL (Docker) | jsonb支持，适合非结构化数据 |
| **缓存/队列** | Redis + Celery | 成熟的任务队列方案 |
| **本地AI引擎** | ComfyUI | 节点式工作流，社区丰富 |
| **本地模型** | Ollama (Qwen2/Llama3) | 剧本生成、文本处理 |
| **视频生成** | Kling/Seedance/Veo/Runway API | 按需选用，质量优先 |
| **图片生成** | SD XL/3.5 + IP-Adapter + LoRA | 角色一致性核心 |
| **后期处理** | FFmpeg | 合成、转码、字幕 |
| **部署** | Docker Compose | 一键启动全部服务 |

## 3. 核心模块

### 3.1 AI 服务层（智能路由）

**职责**：统一管理本地模型和云端API的调用策略。

| 任务 | 优先引擎 | 备选 | 策略 |
|------|---------|------|------|
| 剧本创意生成 | Ollama (Qwen2-7B) | DeepSeek/GPT-4o | 优先本地，长文本切云端 |
| 角色描述提取 | Ollama | Claude Haiku | 本地批处理 |
| 视频提示词生成 | 云端API | - | 强制云端（需要高质量） |
| 敏感词审核 | Ollama (小模型) | 云端审核API | 本地优先（秒级响应） |
| 剧本节奏优化 | 云端API | - | 云端（需要理解力） |

**关键能力**：
- SSE 流式输出（前端实时显示生成过程）
- 自动降级（本地超时 → 切云端）
- 成本追踪（每次调用记录token/费用）

### 3.2 剧本生成模块

**输入**：创意关键词 / 小说片段 / 参考剧本
**输出**：结构化剧本（每集对话 + 动作 + 情绪标注）

**核心功能**：
- **模板库**：预置 10+ 爆款模板（赘婿逆袭、霸总甜宠、悬疑反转、古风仙侠等）
- **风格参考**：上传参考剧本，AI模仿其风格/节奏/反转密度
- **结构化输出**：每集自动拆分为场景（景别 + 角色动作 + 对话 + 情绪）
- **节奏分析**：生成情绪曲线，标注虐点/爽点/钩子分布
- **人工编辑闭环**：块级编辑器，可拖拽调整场景顺序

### 3.3 角色设计模块（数字演员系统）

**核心概念**：每个角色是一个"数字演员"，包含完整的视觉资产。

**数字演员资产清单**：
```
角色卡/
├── 基础信息：姓名、年龄、性格、背景故事
├── 外观描述：结构化外观特征（用于提示词）
├── 参考图集：10+ 不同角度/表情的参考图（IP-Adapter/InstantID生成）
├── LoRA模型：专属角色LoRA（可选，核心角色才训练）
├── 声音ID：TTS音色（预留）
└── 平台绑定：Kling绑定主体ID等
```

**角色一致性三级保障**：
1. **平台级**：利用 Kling 等平台的"绑定主体"功能
2. **工作流级**：ComfyUI 中 IP-Adapter + LoRA 组合工作流
3. **提示词级**：标准化结构化角色描述提示词

**关系图谱**：ECharts/G6 展示角色关系网，支持可视化编辑。

### 3.4 分镜设计模块

**输入**：结构化剧本
**输出**：每个镜头的详细分镜卡 + 视频提示词

**分镜卡内容**：
- 景别（远景/中景/近景/特写）
- 运镜方式（推/拉/摇/移/跟/固定）
- 角色位置、动作、表情
- 环境描述 + 光线 + 时间
- 英文视频生成提示词
- 参考图片（ComfyUI生成）

**高级功能**：
- 同一场景 2-3 个镜头方案并排对比
- 时间轴视图，拖拽调整镜头顺序
- 视频预览（ComfyUI AnimateDiff 粗略预览 或 云端API）

### 3.5 视频生成调度模块

**职责**：作为"制片主任"，调度多平台视频生成任务。

**平台适配层**：
```
统一任务格式 → 适配器模式 → Kling API / Seedance API / Veo API / Runway API
```

**调度策略**：
- 智能分配：根据镜头特点选最合适的平台（人像用Kling，特效用Veo等）
- 并发控制：每平台限制并发数，防止限流
- 失败重试：自动切换备选平台
- 批量优化：利用 Seedance 2.0 批量排队（最多20个）
- 成本追踪：实时统计各平台费用

### 3.6 后期合成模块

**FFmpeg自动化流水线**：
```
原始片段 → 角色一致性后处理(ComfyUI) → 剪辑合成 → 配音(TTS)
→ 字幕(SRT/硬字幕) → 转码(多平台格式) → 成品
```

**多平台格式适配**：
| 平台 | 分辨率 | 时长 | 字幕 | 文件大小 |
|------|--------|------|------|---------|
| 抖音 | 1080x1920 | ≤3分钟 | 硬字幕+SRT | ≤100MB |
| 快手 | 720x1280 | ≤2分钟 | 硬字幕 | ≤80MB |
| YouTube Shorts | 1080x1920 | ≤60秒 | SRT+硬字幕 | ≤200MB |
| 微信视频号 | 1080x1920 | ≤2分钟 | 硬字幕 | ≤100MB |

### 3.7 项目管理模块

**功能**：
- 项目列表 + 状态看板（草稿/生成中/待发布/已发布）
- 版本快照（每次保存自动生成版本，支持回退/对比）
- 资产库（BGM、音效、背景图、角色参考图统一管理）
- 导出（一键导出完整项目包：剧本+分镜+素材+成品视频）

### 3.8 发布管理模块

**功能**：
- 多平台一键发布（或导出各平台专用包）
- 发布前合规扫描（敏感词 + 风险画面检测）
- 发布状态追踪
- 基础数据统计（播放量/完播率，如果API支持）

## 4. 数据库设计（核心表）

```sql
-- 项目
projects (id, name, status, template_type, created_at)

-- 剧本（支持多版本）
scripts (id, project_id, version, content_jsonb, style_config, is_current)

-- 角色（数字演员）
characters (id, project_id, name, traits_jsonb, reference_images,
            lora_path, platform_bindings_jsonb)

-- 分镜
storyboards (id, script_id, episode_no, shot_no, shot_type, camera_move,
             prompt_text, reference_image, approved)

-- 视频任务（调度核心）
video_tasks (id, storyboard_id, platform, status, result_url,
             cost, created_at, completed_at)

-- 发布
publications (id, project_id, platform, status, platform_id, metrics_jsonb)

-- 资产库
assets (id, project_id, type, name, file_path, metadata_jsonb)
```

## 5. 实施路线图

### 第一阶段：基础设施（第1-2周）

**目标**：跑通最小闭环（剧本生成 → 输出文本）

| 任务 | 交付物 |
|------|--------|
| 项目骨架搭建 | 目录结构 + Docker Compose + 配置 |
| 数据库设计 | PostgreSQL + Alembic 迁移 |
| AI 服务层 | Ollama 连接 + 云端API路由 + SSE |
| 基础前端 | Vue 3 项目 + 路由 + 暗色主题框架 |

**验收标准**：能通过前端输入主题，调用 AI 生成一段剧本文本。

### 第二阶段：核心创作（第3-4周）

**目标**：完成剧本 + 角色 + 分镜的文本创作流程

| 任务 | 交付物 |
|------|--------|
| 剧本生成模块 | 模板库 + 结构化输出 + 块级编辑器 |
| 角色设计模块 | 角色卡 + 关系图谱(ECharts) |
| 分镜设计模块 | 自动分镜 + 分镜卡编辑 + 时间轴 |
| 项目管理 | 项目列表 + 版本快照 + 资产库 |

**验收标准**：能完成从创意到完整分镜脚本的全文本流程。

### 第三阶段：视觉生产（第5-6周）

**目标**：接入图片/视频生成，跑通视觉生产流程

| 任务 | 交付物 |
|------|--------|
| ComfyUI 集成 | 安装部署 + API连接 + 基础工作流 |
| 角色视觉 | SD XL生成参考图 + IP-Adapter一致性 |
| 分镜视觉 | 分镜参考图生成 |
| 视频API集成 | Kling/Seedance API适配器 + 任务调度 |
| Celery异步队列 | 任务提交/监控/重试机制 |

**验收标准**：能生成角色参考图 + 分镜参考图 + 单个视频片段。

### 第四阶段：制片流水线（第7-8周）

**目标**：跑通从剧本到成片的完整流水线

| 任务 | 交付物 |
|------|--------|
| 视频批量生成 | 多镜头批量任务调度 + 智能平台选择 |
| 后期合成 | FFmpeg自动剪辑 + 配音 + 字幕 |
| 多平台适配 | 格式转换 + 各平台输出包 |
| 发布管理 | 合规扫描 + 多平台发布/导出 |

**验收标准**：输入剧本 → 自动产出多平台成品视频。

### 第五阶段：打磨优化（第9-10周）

**目标**：提升质量和效率到商用水平

| 任务 | 交付物 |
|------|--------|
| LoRA训练 | 核心角色专属LoRA，极致一致性 |
| 成本控制 | 预算告警 + 费用看板 + 智能路由优化 |
| 前端打磨 | 节奏波形图 + 快捷键 + 编辑体验优化 |
| 稳定性 | 错误处理 + 任务恢复 + 日志完善 |

**验收标准**：月产3部短剧，质量达到商业发布标准。

## 6. 关键风险与应对

| 风险 | 影响 | 应对 |
|------|------|------|
| 角色一致性不达标 | 成品质量差 | 三级保障：平台绑定 + IP-Adapter + LoRA |
| 视频API成本失控 | 预算超支 | 成本追踪 + 本地优先 + 预算告警 |
| ComfyUI学习曲线陡 | 开发进度慢 | 先用API直接调用，后期再接入ComfyUI |
| 多平台API变更 | 功能中断 | 适配器模式隔离变化 |
