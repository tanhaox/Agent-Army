# Video Transcribe

从视频链接提取完整文稿，支持多平台视频处理。

## 支持平台

- YouTube
- B站 (bilibili.com)
- 今日头条
- 抖音

## 工作流程

1. **下载音频**：使用 yt-dlp 下载最低质量的音频文件
2. **提取字幕**：优先提取平台字幕，按以下优先级选择：
   - 简体中文
   - 繁体中文（自动转换为简体）
   - 英文（保留原文并翻译为简体中文）
3. **语音识别**：如无字幕，使用 Whisper 进行语音识别
4. **说话人分离**：如是对话类视频，使用 pyannote.audio 区分人物（人物A、人物B、人物C...）
5. **翻译**：英文内容自动翻译为简体中文（保留英文原文）
6. **输出**：生成 .txt 文件，保存在 `C:\AI-Agent-Local\.claude\docs` 目录

## 使用方法

用户提供视频链接，skill 自动处理并生成文稿文件。

### 输入格式
```
<视频链接>
```

### 输出格式
- 文件名：基于视频标题自动生成
- 文件格式：.txt 纯文本
- 内容结构：
  - 段落分隔
  - 对话视频包含人物标签（人物A: ...）
  - 英文内容保留原文+中文翻译

## 技术依赖

- yt-dlp: 视频下载和字幕提取
- whisper: 语音识别
- pyannote.audio: 说话人分离
- openai/deepseek/豆包/kimi: AI 翻译

## 注意事项

- 不需要视频文件，仅下载音频
- 下载最低质量以节省带宽和空间
- 音频文件为过渡文件，处理完成后可删除
- 输出目录自动创建（如不存在）
