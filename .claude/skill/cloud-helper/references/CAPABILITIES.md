# Qwen1.8B 本地 AI 能力扩展指南

## 模型基本信息

| 参数 | 数值 |
|------|------|
| 模型名称 | Qwen1.8B |
| 参数量 | 约 12.8B (128B) |
| 上下文长度 | 约 8K tokens |
| 模型类型 | 通义大语言模型 |
| 主要能力 | 文本生成、翻译、摘要、代码生成、对话 |

## 在 video-transcribe 中的扩展用法

### 当前的使用方式
```python main.py <视频链接>
# 默认：下载(本地) + 识别(本地 Whisper) + 分离(本地) + 翻译(云端 Token)

python main.py <视频链接> --translate ollama
# 完全使用本地 AI：下载 + 识别 + 分离 + 翻译(本地 Ollama)
```

### 扩展使用方式

#### 1. 语音识别增强
```python
# 当前：Whisper 基础识别
# 扩展：Whisper + 本地 AI 后处理（说话人分离、格式优化等）

# 示例：修改 transcribe.py 使用本地 AI 进行增强
result = whisper.transcribe(audio)
enhanced_result = ollama_translate.analyze(
    f"以下语音识别结果，请进行说话人分离和格式优化：\n{result}",
    service='ollama', api_url='http://localhost:11434', model='qwen:1.8b'
)
```

#### 2. 翻译质量提升
```python
# 当前：翻译（云端或本地 Ollama）
# 扩展：翻译后使用本地 AI 进行校对和润色

# 示例：修改 translate.py
original_translation = translate_text(text, 'deepseek')
enhanced_translation = ollama_translate.analyze(
    f"以下翻译，请优化语言表达和准确性：\n{original_translation}",
    service='ollama', api_url='http://localhost:11434', model='qwen:1.8b'
)
```

#### 3. 智能摘要生成
```python
# 当前：直接返回识别文本
# 扩展：识别后使用本地 AI 生成结构化摘要

# 示例：添加到 main.py
transcript = transcribe_audio(audio_path)
summary = ollama_translate.analyze(
    f"以下视频文稿，请生成结构化摘要，包括：主题、要点、时间线\n{transcript}",
    service='ollama', api_url='http://localhost:11434', model='qwen:1.8b'
)
```

## 本地 AI Token 消耗估算

| 任务类型 | 输入长度 | 输出 tokens | 消耗 |
|---------|----------|----------|----------|
| 翻译 | 1000 字符 | ~1000 tokens | 低 |
| 摘要 | 5000 字符 | ~1000 tokens | 低 |
| 分析 | 2000 字符 | ~500 tokens | 低 |
| 代码生成 | 500 字符 | ~1000 tokens | 低 |
| 对话（10轮）| 500 字符 | ~2000 tokens/轮 | 低 |

**估算：** 完整处理一个 10 分钟视频（约 2000 字符文稿）使用本地 AI 扩展功能，总 Token 消耗约 2000-5000 tokens，成本极低。

## 推荐架构调整

### 方案 A：保守架构
- video-transcribe 只负责基础下载 + Whisper 识别
- cloud-helper 处理所有 AI 增强任务（翻译、分析、摘要等）
- 分工明确，易于维护

### 方案 B：渐进式扩展
1. 先实现本地 AI 集成到 video-transcribe
   - 增强说话人分离质量
   - 翻译结果润色
2. 添加智能摘要功能

### 方案 C：本地优先策略
1. 常用本地 AI 处理 90% 以上任务
2. 复杂任务才使用云端 Token
3. 降低 Token 成本

## API 接口规范

本地 Ollama API（http://localhost:11434）

```
POST /api/generate
{
  "model": "qwen:1.8b",
  "prompt": "<你的任务>",
  "stream": false
}
```

## 注意事项

1. **上下文管理**：Qwen1.8B 支持 8K 上下文，可以处理较长文本
2. **并发处理**：多个任务可以并行处理，提高效率
3. **错误处理**：API 调用失败时应有降级方案
4. **Token 监控**：记录每次调用的 Token 消耗
