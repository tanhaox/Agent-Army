## 触发条件

当用户提出以下类型需求时，**必须先执行 GitHub 搜索**：
- "做一个 X 工具"
- "写一个 X 功能"
- "开发 X 系统"
- "需要 X 功能"
- "实现 X 需求"
- "帮我写代码做 X"
- 或者任何明确的功能开发需求

## 搜索策略

### 关键词提取
从用户需求中提取核心关键词：
- 功能词：爬虫、提取、转换、分析、可视化、部署...
- 领域词：PDF、Excel、视频、音频、图片、数据库...
- 技术词：Python、JavaScript、React、Vue、Go...

### GitHub API 搜索
```bash
# 使用 scripts/github_search.py 进行搜索
python scripts/github_search.py "关键词" --limit 3
```

### 匹配度评估
- **完全匹配**：项目描述/标题包含所有核心关键词 + Star > 100 + 近期活跃
- **相近匹配**：项目描述/标题包含部分关键词 + Star > 500 + 活跃
- **一般匹配**：功能相关 + Star > 1000

## Git Clone 流程

用户选择项目后，执行：

```bash
# 使用 scripts/github_clone.py 进行克隆
python scripts/github_clone.py "https://github.com/用户/项目"
```

克隆目录：`C:\AI-Agent-Local\github_downloads\项目名`

## 用户交互决策

1. **找到完全匹配项目**：
   - 展示项目信息
   - 询问："这个项目完全符合你的需求，是否下载？[y/n]"

2. **找到相近项目**：
   - 展示 3 个选项
   - 询问："这些项目功能相近，你可以在此基础上修改，选择哪个？[1/2/3/0]"

3. **无合适项目**：
   - 明确说明："GitHub 未找到合适项目，将进入 AI 编程模式"
   - 询问："确认进入 AI 编程模式？[y/n]"

## 配置说明

### GitHub Token（可选）
设置环境变量提高 API 速率限制：
```bash
set GITHUB_TOKEN=你的Personal_Access_Token
```

获取 Token：GitHub → Settings → Developer settings → Personal access tokens

### 下载目录
默认：`C:\AI-Agent-Local\github_downloads`
可在 `scripts/github_clone.py` 中修改

## 常用命令示例

```python
# 搜索 PDF 提取工具
github_search("PDF提取", limit=3)

# 搜索视频转字幕项目
github_search("视频字幕", limit=3)

# 克隆仓库
github_clone("https://github.com/user/project")
```

## 注意事项

1. **Token 限制**：无 Token 时每小时 60 次请求，建议配置 Token
2. **中文支持**：GitHub 搜索对中文支持有限，建议使用中英文关键词组合
3. **项目质量**：优先推荐 Star > 100 且最近 6 个月有更新的项目
4. **许可证**：推荐 MIT/Apache 2.0 等宽松许可证项目

## 集成到工作流

当用户提出需求时，执行流程：

1. **Step 1**: 调用 `github_search.py` 搜索
2. **Step 2**: 根据搜索结果展示推荐项目
3. **Step 3**: 等待用户选择
4. **Step 4**: 如选择项目 → `github_clone.py` 下载
5. **Step 5**: 如跳过 → 进入 AI 编程模式

**重要**：不要跳过 GitHub 搜索直接编程！这是全局优先级 Skill，必须先执行。
