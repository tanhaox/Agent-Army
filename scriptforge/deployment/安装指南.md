# ScriptForge v1.0 安装指南

## 系统要求

| 项目 | 最低要求 | 推荐 |
|------|---------|------|
| 操作系统 | Windows 10/11 64位 | Windows 11 |
| 内存 | 8 GB | 16 GB+ |
| 磁盘空间 | 20 GB | 50 GB+ |
| GPU | 无（CPU 模式可用） | NVIDIA RTX 系列 |
| 网络 | 安装时需要，运行时可选 | 宽带 |

---

## 安装步骤

### 第一步：检查环境

1. 双击打开 `deployment/env-checker.html`
2. 按照页面指引，依次检测三个环境依赖：
   - **Docker Desktop**（必需）
   - **NVIDIA 显卡驱动**（可选，无 GPU 可跳过）
   - **NVIDIA Container Toolkit**（可选，无 GPU 可跳过）
3. 确认页面显示"环境就绪"后继续

### 第二步：配置环境变量

1. 将 `deployment/.env.example` 复制到 `backend/.env`
2. 用文本编辑器打开 `backend/.env`
3. **必填项**：将 `DEEPSEEK_API_KEY` 改为你的 DeepSeek API Key
   ```
   DEEPSEEK_API_KEY=sk-xxxxxxxxxxxxxxxxxxxxxxxx
   ```
   API Key 获取地址：https://platform.deepseek.com/api_keys
4. 其他配置项通常无需修改

### 第三步：安装启动

1. 双击 `deployment/setup.bat`
2. 等待安装完成（首次约 5-10 分钟）
3. 看到"启动成功"提示后，按任意键自动打开浏览器

### 第四步：开始使用

1. 浏览器打开 http://localhost:5173
2. 进入左侧导航栏的 **系统设置** 页面
3. 在 **抖音 Cookie** 区域粘贴你的 Cookie（从浏览器登录抖音后获取）
4. 进入 **学习中心**，输入主播主页 URL 开始学习

## 常用操作

### 查看服务状态
```bash
docker compose ps
```

### 查看日志
```bash
# 查看所有服务日志
docker compose logs -f

# 只看后端日志
docker compose logs -f backend

# 只看 Celery 日志
docker compose logs -f celery-worker
```

### 停止服务
```bash
docker compose down
```

### 更新系统
双击 `deployment/update.bat`，脚本会自动备份、重新构建、重启。

## 常见问题 FAQ

### Q: Docker Desktop 未启动
**现象**：setup.bat 提示"未检测到 Docker Desktop"

**解决**：
1. 打开 Docker Desktop 应用
2. 等待左下角状态变为"Engine running"
3. 重新运行 setup.bat

### Q: 端口被占用
**现象**：启动时报错 `port is already allocated`

**解决**：
1. 编辑 `backend/.env` 修改端口号
2. 例如将 `FRONTEND_PORT=5173` 改为 `FRONTEND_PORT=8080`
3. 重新运行 `docker compose up -d`

### Q: 抖音 Cookie 过期
**现象**：学习中心导入时提示"cookies 已过期"

**解决**：
1. 用浏览器打开 https://www.douyin.com 并登录
2. 按 F12 打开开发者工具 → Application → Cookies
3. 复制全部 Cookie 值
4. 在系统设置页面粘贴更新

### Q: GPU 加速不可用
**现象**：日志中出现 CUDA 相关错误

**解决**：
1. 确认已安装 NVIDIA 显卡驱动（`nvidia-smi` 命令可用）
2. 确认已安装 NVIDIA Container Toolkit
3. 重启 Docker Desktop
4. 如果没有 NVIDIA 显卡，系统会自动降级为 CPU 模式（转写速度较慢）

### Q: 数据库连接失败
**现象**：后端日志提示 "connection refused"

**解决**：
1. 等待 PostgreSQL 完全启动（约 10-20 秒）
2. 检查 `docker compose ps` 确认 postgres 服务状态为 healthy
3. 重启后端：`docker compose restart backend`

### Q: 如何备份数据
数据存储在 Docker 卷中，导出方法：
```bash
# 备份数据库
docker compose exec postgres pg_dump -U scriptforge scriptforge > backup.sql

# 恢复数据库
cat backup.sql | docker compose exec -T postgres psql -U scriptforge scriptforge
```
